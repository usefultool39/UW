# 《边境回声》原创视觉风格圣经 v0.1

本文件是生成、搜索、委托和评审素材时的共同语言。它描述设计原则，不要求模仿任何现成作品或在提示词里写作品名。

## 1. 核心体验翻译

| 体验目标 | 视觉翻译 |
|---|---|
| 即时反馈、短循环 | 高对比目标、短促动画、奖励颜色稳定、按钮状态明显 |
| 清晰数值决策 | 时间/资源/关系图标始终可辨；避免装饰覆盖数字 |
| 叙事悬念 | 在正常田园秩序中放入一处不合逻辑的“缺失、静止、反向光” |
| 日程/关系推进 | 温暖生活材质与人物表情承担长期回报；不是每次都靠大特效 |
| 固定 NPC→未来 agent | 人物有稳定剪影、色彩和表情语法，换台词来源也不会失去角色感 |

## 2. 一句话风格

**细雨中的可居住边境村 + 记录员工具感 UI + 克制发光术式 + 逐渐侵入日常的静默异常。**

## 3. 原创化边界

- 可以参考“短循环、清晰数值、悬念、日程关系”这些设计原则。
- 不复制任何现有游戏的角色脸、服装、武器、徽章、卡牌边框、地图结构、字体 logo 或特效构图。
- 不在 AI 提示词中要求“某某游戏/动画原画风”；改写为可观察属性，如“高机位 3/4 手绘地图、暖田园与冷异常对比、UI 低装饰高可读”。
- 角色名属于现有项目内容，但美术必须走原创剪影和服装设计，避免一眼识别为现成 IP 定妆。

|---|---|---|
| `ink-950` | 主背景 | `#071018` |

| `paper-100` | 主文字 | `#FFF7DF` |

| `gold-400` | 主目标/神圣术 | `#F6D36E` |
| `cyan-400` | 线索/地点/信息 | `#7DD3FC` |
| `green-400` | 信任/完成 | `#86EFAC` |

规则：正常世界以自然绿、木色、纸色为主；异常不要简单“全画面紫色”，而是让声音、局部饱和、运动和光向先出错。

## 5. 地图与环境

- 镜头：高机位 3/4 俯视，优先导航清晰，不追求透视炫技。
- 道路：主路宽度/亮度稳定，缩放后仍连续。
- 建筑：教会书库、家、广场、北门、巨树方向有不同剪影。
- 纹理：湿草、石路、木屋、河流细节足够，但角色脚下 24–36px 区域避免高频噪点。
- 光线：正常区域暖而克制；异常区域可用不自然静止、反向高光、缺失飞鸟、被截断的雨线。
- UI 安全区：桌面左右各至少 22% 可被半透明 UI 覆盖；移动端下半部需为文本与 CTA 留低细节区。

## 6. 角色设计

### 共通比例

- 地图 token：头身比可略夸张以便缩小识别；不做纯可爱 chibi。
- 肖像：半身 3/4，肩线和视线统一，面部情绪靠眉眼、颈肩和手势共同表达。
- 服装：边境日常、记录/劳动/防护功能优先；避免无理由复杂装甲。
- 识别：每人一个主色、一个形状语言、一个功能物件。

### 见习记录员

- 主色：深墨 + 冷蓝。
- 形状：窄长、轻便、便于移动。
- 物件：记录册、短笔、细绳标签或便携刻印工具。
- 气质：不是天选英雄；“观察和选择”比“力量”更重要。

### 爱丽丝

- 主色：麦金 + 冷青蓝点缀。
- 形状：稳定三角、护肩/披肩不过度夸张。
- 物件：圈注过的记录页、轻型护具、用于确认距离的工具。
- 情绪：担忧往往先表现为判断和控制风险，不先表现为柔弱。

### 尤吉欧

- 主色：冷蓝 + 木/麻自然色。
- 形状：柔和纵向、动作可靠。
- 物件：训练或劳动工具，不能直接复制现成标志性武器。
- 情绪：温和不是被动；面对风险时会做清楚的撤退/陪同行动判断。

### 支持角色

- 赛尔卡：浅粉/莓色，小型圆形语言，疗愈但不幼态。
- 加利塔：苔绿/木色，宽肩矩形语言，哨兵和劳动者气质。
- 加斯夫特：灰白/旧皮革，稳重梯形语言，权威来自经验而非华服。

## 7. UI 语言

- 面板：深墨蓝半透明，左侧或顶部用一条金/青色细线表达层级；不做厚重石框或卡牌边框。
- 主 CTA：金色暖亮；同屏只允许一个最强金色按钮。
- 次 CTA：深色描边；危险选择用琥珀/玫红，不和奖励色混用。
- 数值：始终由图标+数字+词语三者至少两项表达；不能只靠颜色。
- 圆角：6–10px；不要过度胶囊化。
- 图标：24px 优先，统一笔画和透视；不在图标内塞文字。
- 动效：150–320ms 为主；奖励可以 450–650ms；避免持续呼吸闪烁造成疲劳。

## 8. 特效语言

- 神圣术：几何圆环、书写轨迹、金/青细线、粒子数量克制。
- 静默线：运动被切断、雨线消失、粒子在一条边界前停住、局部折射而非大面积烟雾。
- 关系回响：柔和扩散波纹、颜色靠角色识别色，不使用爱心爆炸。
- 紧张：轻微错位、短促琥珀脉冲、边缘收紧；不靠全屏红闪。
- 奖励：先显示“发生了什么”，再给闪光；特效不能盖住数字。

## 9. 评审时的五个问题

1. 缩到实际游戏尺寸仍能看懂吗？
2. 第一眼知道哪里可操作、哪里是反馈吗？
3. 它是否服务“记录、判断、关系、异常”，还是只是好看？
4. 是否能在不看文件名时与同组素材认作同一世界？
5. 是否存在现成 IP 的脸、服装、徽记、构图或 UI 复制风险？
