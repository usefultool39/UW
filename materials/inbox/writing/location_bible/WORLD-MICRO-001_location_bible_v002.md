## 0. 范围与术语

- 范围：卢利特村（含家庭、教会、书库、伐木场、北门、村道、广场）+ 尽头山脉外侧（含洞穴入口、规则边界线）。
- 术语：玩家可见文本以 `uwCanonText.js` 为唯一裁决；本文件用规范译名（卢利特村、巨神树、巨神树伐木场、教会书库、教会回廊、北门、尽头山脉、北方洞窟等）。
- 现有 `scene_id` 引用：`gigas_clearing`、`church_library`、`home_hearth`、`north_gate`、`village_square`、`end_mountains_entrance`、`silence_line_boundary`。
- 三栏分类：A = 官方明确；B = 原作·动画明确但当前官方网页摘要未覆盖；C = 项目原创补充。

## 1. 卢利特村（整体）`[A]`

- 官方固定（A）："Kirito and his childhood friend Eugeo were raised in Rulid village"（https://sao-alicization.com/1st/story/01.html）。
- **可玩活动**：桐人的日常安排（与 Eugeo 一起伐木、与 Alice 一起走村道、帮 Selka 在书库整理）。
- **可发现线索**：村道传闻（"北边最近风不太对"）、北门值班记录、村务会议告示（禁忌目录节选）。
- **相关人物**：桐人、尤吉欧、爱丽丝、赛尔卡、加利塔、加斯夫特、Alice 父亲。
- **风险**：村内无军事风险；禁忌目录在村中以"风俗 / 习惯"形式被遵守，**不**主动触发。
- **后续剧情用途**：作为 N01–N04（Act 0 / Act 1）与 N07–N10（Act 3）的默认发生地。
- **关联节点**：N01（日常）/ N02（天职）/ N03（讨论）/ N04（出发准备）/ N07（返回）/ N08（骑士宣告）/ N09（告别）/ N10（带走）。

## 2. 桐人和尤吉欧的家（炉边）`[A + C]`

- 官方固定（A）：Eugeo 与 Kirito 共同生活（官方 Ep.1 描述三人共同日常）。
- 房间布局（C）：东墙放柴 / 斧 / 测距粉；西墙靠窗是小餐桌；炉火在北侧；门外是去巨神树伐木场的土路。
- **可玩活动**：Eugeo 的准备动作（看天气、磨斧）、餐桌上的对话（N01 / N03）、炉火日结算。
- **可发现线索**：Eugeo 的笔记（手绘年轮 / 风向）、炉边悬挂的"安全提醒"、碗底的"上次多放盐"痕迹。
- **相关人物**：桐人、尤吉欧、爱丽丝（送餐）、赛尔卡（在窗外探视）。
- **风险**：无；与巨神树伐木场之间的连接有"门口风大"的环境提示。
- **后续剧情用途**：N01（炉边日常）/ N03（禁忌目录讨论）的主舞台。

## 3. 爱丽丝的家（村长家）`[A + C]`

- 官方固定（A）：Alice 是 "the daughter of the chief of Rulid Village"（https://sao-alicization.com/1st/character/）。
- 项目原创（C）：她家**靠近村中心偏北**；父亲（村务长代行人加斯夫特不在时由父亲本人主持）偶尔到访但在 N08 之前**不**出场。
- **可玩活动**：送餐途中（Alice 路线）、与父亲正式对话（**仅在 N08 / N09 出场**）。
- **可发现线索**：Alice 的"父亲近期叮嘱不要靠近北门"对话（C：项目原创补充）。
- **相关人物**：爱丽丝、其父、玩家（按事件触发）。
- **风险**：家庭内部无风险；外部风险是"父亲训话"对 Alice 行动的约束。
- **后续剧情用途**：N09 告别场景（爱丽丝与父亲 / 妹妹告别）。
- **关联节点**：N09。

## 4. 教会（Church）`[A + C]`

- 项目原创约束（C）：教会是"禁忌目录的发布渠道之一"；外墙有回廊（`教会回廊`）；回廊一侧通向书库。
- **可玩活动**：在回廊避雨、旁听教会对禁忌目录节选的朗读（每三日一次）、向北门外远望。
- **可发现线索**：回廊柱子上刻有"北门不越过"等可观察禁忌条目；地面石缝方向是"北"。
- **相关人物**：赛尔卡（在书库帮工）、书库其他帮手、爱丽丝（送药草时路过）。
- **风险**：无。
- **后续剧情用途**：作为 N04 出发前的"送行点"或"路过点"；**不写教会内部政治**。
- **关联节点**：N04（出发前可路过）。

## 5. 教会书库（`church_library`）`[A + C]`

- 项目原创（C）：书库在教会东侧；旧记录按页码排列；最旧的一批在第 10–20 页之间；保管人是赛尔卡与 1–2 名帮手。
- 内部动线：进 → 借阅台（赛尔卡站位）→ 阅览室（中央桌 + 三张侧桌）→ 旧记录柜（锁，由赛尔卡开）→ 后门通回廊。
- **可玩活动**：借阅新记录、阅读、抄录；**14.5 页夹层属 C 类可选支线（见 §13）**，**不**进关键节点表。
- **可发现线索**：借阅台上的"近期被借出"清单、旧记录柜的锁（赛尔卡钥匙）。
- **相关人物**：赛尔卡、爱丽丝（送药草路过）、桐人。
- **风险**：无；唯一"被看见"的紧张来源是"赛尔卡有没有注意到你拿了这页"。
- **后续剧情用途**：N04 出发前可路过（**非**关键节点）。

## 6. 巨神树伐木场（`gigas_clearing`）`[A + C]`

- 官方固定（A）："a colossal black tree called the Gigas Cedar. This is their Calling."（https://sao-alicization.com/1st/story/01.html）。
- 物理布局（C）：树身直径约占场景中心；四周为平整的伐木台。
- 工具（C）：斧（Eugeo / 桐人共用）、测距粉、麻绳。
- 天气（C）：常态为多云 / 短时阵雨；风向偏北 / 偏西北。
- **可玩活动**：挥斧、计数、听风声、读斧痕、记年轮、听 Eugeo 的口述、对比今天 / 昨天的"下数"。
- **可发现线索**：斧痕深度异常（"今天少砍 3 下"）、地面年轮的"靠北侧长得慢"现象。
- **相关人物**：桐人、尤吉欧、加利塔（路过）。
- **风险**：体力耗尽（巨神树天职压力）；**两息风声断点属 C 类可选支线（见 §13）**，不构成关键节点。
- **后续剧情用途**：N02（天职日常）的主舞台。
- **关联节点**：N02。

## 7. 北门（`north_gate`）`[A + C]`

- 项目原创（C）：北门是卢利特村北侧的村门；门外是森林 + 远方的尽头山脉；门旁是加利塔的值班棚。
- 值班棚内：值班记录本（每日一张）、火把、备用绳、一面旧铜锣。
- **可玩活动**：看值班记录、听加利塔口述、与加利塔同步今日观察、听远处风向。
- **可发现线索**：值班记录上"昨日断风时长"的数值、远眺尽头山脉的山脊线。
- **相关人物**：加利塔、加斯夫特（被通知后赶到）、桐人。
- **风险**：北门外的森林**已被默认标为"日常不可越"**；越门不立即触发禁忌目录执行，但属"主动进入风险区"。
- **后续剧情用途**：N04（出发前最后窗口）/ N07（返回抵达）/ N10（爱丽丝被带走地点）的主舞台。
- **关联节点**：N04 / N07 / N10。

## 8. 村道 / 中央广场（`village_square`）`[A + C]`

- 项目原创（C）：村中央有一块不规则石板地；旁有水井、公告柱。
- **可玩活动**：看公告柱（禁忌目录节选、村务会议告示）、听村民闲谈、给水井打水。
- **可发现线索**：公告柱上"近期北门风大"的告示、村民口耳相传的传闻。
- **相关人物**：村民（项目原创 1–3 名背景）、爱丽丝（送餐路线经过）、桐人、尤吉欧。
- **风险**：无。
- **后续剧情用途**：N01（日常）/ N08（整合骑士宣告）/ N09（告别）的主舞台。
- **关联节点**：N01 / N08 / N09。

## 9. 村外森林 / 北门至尽头山脉之间 `[C]`

- 项目原创约束：森林中段是三人前往 End Mountains 洞窟的路线必经区。
- 天气：上午多云 / 短时阵雨；午后风向开始变。
- **可玩活动**：观察脚印、对比测距粉痕迹、听鸟声、对比斧痕方向。
- **可发现线索**：地面测距粉的"颜色比去年淡"现象、远处山脊的"洞口阴影"在午后更明显。
- **相关人物**：桐人、尤吉欧、爱丽丝。
- **风险**：体力下降；鸟声变化是"接近边界"的可观察信号（**不**是 v001 那种"两息断点"作为关键证据）。
- **后续剧情用途**：N04（前往）/ N05（在洞穴外侧前的一段）/ N07（返回）的路线段。
- **关联节点**：N04 / N05 / N07。

## 10. 尽头山脉洞穴入口（`end_mountains_entrance`）`[A + B]`

- 官方固定（A）：Ep.1 "the fabled cave in the End Mountains"（https://sao-alicization.com/1st/story/01.html）。
- **B 类原作明确**：三人到达洞穴附近时遇到来自暗黑界的受伤者 / 倒下的存在（原作·动画明确，**当前官方网页摘要未覆盖**）。
- 物理形态（C）：洞穴入口外侧有一块可站立的石板；洞穴入口上方的岩石在午后会有"鸟声到此为止"的明确边界。
- **可玩活动**：在洞穴外侧与 Eugeo / Alice 对齐"安全距离"与"是否施援"、把记录本放在石板上、听受伤者的存在信号。
- **可发现线索**：受伤者的存在（B：原作明确）、洞穴内外的压感差异（C）。
- **相关人物**：桐人、尤吉欧、爱丽丝；**N08 之后**整合骑士 Deusolbert 等出现在**村中**（**不**在山侧）。
- **风险**：越线 = 触碰 / 越过禁忌目录的"北门不越过"条目。
- **后续剧情用途**：N05（接触受伤者）/ N06（爱丽丝越界救人）的主舞台。
- **关联节点**：N05 / N06。

> ⚠️ **v002 关键修正**：v001 把"整合骑士在山侧执行逮捕"作为终点，v002 改为 N08 之后整合骑士**在村中**宣告与带走。山侧**不**有整合骑士。

## 11. 静默线 / 规则边界线（`silence_line_boundary`）`[A + B]`

- **B 类原作明确**：禁忌目录规定的"北门不越过"边界在空间上的投影；爱丽丝越界即触犯此边界（原作·动画明确，**当前官方网页摘要未覆盖**）。
- 项目约束（C）：位于尽头山脉洞穴外侧；玩家可观察到的"压感"是"鸟声停止 + 风向反向"。
- **可玩活动**：在边界外侧做记录、与 Eugeo / Alice 同步判断。
- **可发现线索**：边界附近的"压感"（C）。
- **相关人物**：桐人、尤吉欧、爱丽丝。
- **风险**：越线即触发禁忌目录（远端执行，由整合骑士在村中宣告）。
- **后续剧情用途**：N06（爱丽丝越界）的物理位置。
- **关联节点**：N06。

## 15. 村民日常 `[C]`

- 早晨：伐木手（Eugeo + 桐人）上工；神圣术见习（Alice）准备药草；书库帮手（Selka）开门；村务长办公。
- 上午：伐木手轮班；北门巡守值班；书库借阅。
- 午餐：送餐 / 村道吃饭；炉边暂休。
- 下午：伐木手继续轮班；神圣术在回廊的朗读；村务会议（每三日一次）。
- 傍晚：回家做饭；炉边晚餐；日结算。
- 夜间：北门夜巡；书库关门；村道少人。

> **项目约束**：上述节奏是默认；`N04`–`N10` 期间，节奏**只会被事件本身**打乱，**不**会被"玩家主动跳日"打乱。

## 16. 风险与失败后果

| 风险 | 后果 | 触发条件 |
|---|---|---|
| 触碰 / 越过边界 | 触犯禁忌目录；触发远端执行（整合骑士在村中宣告） | 玩家 / Alice 越过静默线 |
| 准备不充分 | 体力归零 / 撤退失败 / 记录本丢失（不影响 N08 触发） | N04 准备选择错误 |
| 隐藏真相回村 | 整合骑士宣告时 N08 / N09 台词更紧 | N07 选 `keep_secret` |
| 立即上报 | 整合骑士宣告时 N08 / N09 台词更稳 | N07 选 `tell_truth_now` |

> **不可改写约束**：N08 / N09 / N10 **不能**被任何玩家选择取消或改变顺序；只能改变台词语气与"最后表达"内容。
