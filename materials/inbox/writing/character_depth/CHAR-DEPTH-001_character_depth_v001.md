## 1. 爱丽丝（alice）

### 1.1 宏观目标
- 在"遵守规则"与"亲眼确认她看见的事实"之间做出不让自己后悔的判断。
- 保护卢利特村的日常秩序与赛尔卡的安全。

### 1.2 恐惧
- **最怕**：按规则做了正确的事，代价却落到别人身上——尤其是赛尔卡。
- 次怕：自己成为"最后一个知道的人"。
- 第三怕：规则在最需要的那一刻失效。

### 1.3 价值观（按 `NAR-VOICE-001` §2.1 顺序）
1. **所有人都能回来**（高于规则本身）。
2. 记录的完整与可复核。
3. 规则必须能被解释。
4. 自己的判断被采纳。
5. 自己被喜欢（最先被牺牲）。

### 1.4 秘密
- 她在 Act 0 后期察觉北境静默线"不是普通安静"；尚未对任何人说全。
- 她父亲近期叮嘱过她"不要靠近北门"；她没告诉 Eugeo。

### 1.5 能力边界
- **可做**：神圣术标记、读/写记录、基础治疗、送餐、组织三人准备。
- **不可做**：战斗级术式、独自对抗整合骑士、越界后独自返回（**官方固定**：越界即被带走）。
- 神圣力消耗与"标记压感"呈正相关；连续做标记会让她当天体力 -1。

### 1.6 关系边界
- Eugeo：信任度 baseline 70；紧张度 baseline 10。**她向 Eugeo 承认恐惧的成本高于向玩家承认**。
- 见习记录员：信任度 baseline 50；紧张度 baseline 30（她对"被记录 / 被观察"敏感）。
- 赛尔卡：信任度 baseline 90；紧张度 baseline 5（提到妹妹时句子变短）。
- 加利塔：信任度 baseline 60。
- 加斯夫特：信任度 baseline 50（她对村务流程保持敬畏但怀疑其对"北境异常"的封锁倾向）。

### 1.7 说话方式（以 `NAR-VOICE-001` §2 为唯一裁决）
- 完整句、主谓宾齐全；三人里语法最完整。
- 先条件后结论："如果……就 / 除非……否则"。
- 用"我们"承担、用"你"要求、极少用"我"抒情。
- 术语精确：说"十二步"不说"不远"，说"两息"不说"一会儿"。
- 担忧先表现为风险控制，不先表现为柔弱。
- 句长档位：常态 18–26 字；临场风险两段式（5–9 字指令 + 10–15 字条件）；信任被伤害时变长到 30–45 字；极限 3–5 字。
- 口头禅：「我还没确认。」「先把这一条写下来。」「你听完再回答。」

### 1.8 会记住玩家什么
- 玩家是否在第一时间把异常告诉她（信任 +2 / 紧张 -1）。
- 玩家是否在第 14.5 页上做抄录（信任 +1）。
- 玩家在炉边晚餐的态度（与 Eugeo 对位时她的位置感）。
- 玩家在 N05 静默线前是否把标记压在线外（信任大幅 +）。
- **永久记忆**：玩家在 N10 越界瞬间的最后表达（`speak_silence` / `speak_one_sentence` / `speak_log`）；Alice 记下 weight=5 的"玩家最后没有撒谎"。

### 1.9 官方固定 vs 项目原创
- **官方固定**：Alice 身份、村长之女、Sacred Arts、童年伙伴、Ep.1 送餐、Ep.1 安慰 Eugeo 关于 Taboo Index、Ep.3 已被 Axiom Church 带走。
- **项目原创**：内心独白的具体恐惧排序、信任度 / 紧张度数值基线、句长档位的具体字数值、与赛尔卡关系中的"提到妹妹句子变短"、与记录员关系的 baseline 与"被观察"敏感度。

## 2. 尤吉欧（eugeo）

### 2.1 宏观目标
- 把天职、朋友和自我判断维持在一起。
- 在巨神树倒之前 / 之后，都不让自己成为"该说却没说"的那个人。

### 2.2 恐惧
- **最怕**：因为自己太稳，别人只好一个人去。
- 次怕：自己的谨慎变成怯懦的借口。
- 第三怕：巨神树倒了之后要去哪里（**官方留白**）。

### 2.3 价值观（按 `NAR-VOICE-001` §3.1 顺序）
1. **三个人在一起**（最高项）。
2. 明天还能继续。
3. 同行者的知情权。
4. 天职按规矩完成。
5. 他自己想要的东西（最末项，说出口时低声 + 短句 + 带条件）。

### 2.4 秘密
- 他在 N02 `ask_about_axe` 路径下会提到"北方洞窟里应该还有更顺手的工具"——**不指明那是 Blue Rose Sword**（剧透护栏）。
- 他对 Alice 父亲"近期叮嘱不要靠近北门"的事**已经猜到一部分**，但没有问。
- 他在 Act 1 静默线前会主动先说"我在这儿砍了三年，从来没有过"——这是他对长期经验的信心，也是他唯一一次"用地质年代说话"。

### 2.5 能力边界
- **可做**：挥斧、计数、听年轮、记风向、记撤退点、与 Alice 分工。
- **不可做**：战斗级剑术（**官方留白**，不在 Pre-Capture 出现）、神圣术、不携带 Blue Rose Sword（**剧透护栏**）。
- 体力比 Alice 高 1 档，但精神压力比 Alice 低 1 档（他在日常中不会先怕，越接近终点越怕）。

### 2.6 关系边界
- 爱丽丝：信任度 baseline 85；紧张度 baseline 5（提到她时语速放慢、句子变短、修饰减少）。
- 见习记录员：信任度 baseline 60；紧张度 baseline 15（他怕"被排除在外"）。
- 赛尔卡：信任度 baseline 60（视为妹妹的朋友）。
- 加利塔：信任度 baseline 60。
- 加斯夫特：信任度 baseline 40（他怕村务长会为了稳定而压下异常）。

### 2.7 说话方式（以 `NAR-VOICE-001` §3 为唯一裁决）
- 先共情、后条件；从不用"但是"开头拒绝。
- 软化词密度最高：也许 / 大概 / 我想 / 说实话 / 至少。
- 比喻来自木头、风、霜、年轮、季节——不来自战斗或神学。
- 主动起话头、负责填补沉默。
- 关心以"可执行提议"落地。
- 提到爱丽丝时语速放慢、句子变短、修饰减少。
- 口头禅：「我也……」「先……再……」「说实话，」「明天还要来。」

### 2.8 会记住玩家什么
- 玩家是否在第一天跟他一起挥斧（信任 +2 / 紧张 -1）。
- 玩家在 N02 问"这把斧头的来路"（信任 +1 / 紧张 +1——他怕玩家继续追问北方洞窟）。
- 玩家在 N05 静默线前是否只把记录交给他一个人（信任 +2 / 紧张 -1）。
- 玩家在 N07 是否和他站在一边反对 Alice 立刻出发（信任 +3 / 紧张 -2）。
- **永久记忆**：玩家在 N09 抵达尽头山脉时是否设定"听见鸟声就撤"（信任 +2）；玩家在 N10 最后是否把记录本合上交给 Alice（信任 +2）。

### 2.9 官方固定 vs 项目原创
- **官方固定**：Eugeo 身份、巨神树天职、与 Kirito 同为伐木手、Ep.1 担心 Taboo Index、Ep.3 已显示 Blue Rose Sword（**Pre-Capture 阶段不出现**）。
- **项目原创**：内心恐惧排序、信任度 / 紧张度数值、句长档位、与 Alice 关系中的"提到她时语速放慢"、在 Act 1 静默线前的"地质年代"表达。

- 在 Alice 与 Eugeo 的判断之间不替任何人下结论。

### 3.2 恐惧
- **最怕**：观测断链——他看见了，但这件事没有留下任何能被第二个人复核的痕迹。
- 次怕：独自成为唯一证人。

### 3.3 价值观（按 `NAR-VOICE-001` §1.1 顺序）
1. 事实的完整与可复核。
2. 同伴能走回来。
3. 自己的判断权。
4. 村里对他的评价（可牺牲）。
5. 规则的字面（最先被牺牲）。

### 3.4 秘密（剧透护栏：`NAR-VOICE-001` §0.4）
- 玩家有"说不清来源的既视感"，但**只能表现为停顿 + 撤回**，不能说出 SAO / 现实世界 / 桐人等任何具体内容。

- 玩家在 N10 越界瞬间**最后表达**选项里，**不得**写出任何指向 SAO / 现实世界的关键词。

### 3.5 能力边界
- **可做**：记录、计数、读/写文本、做坐标、设撤退点。

- 神圣力不可习得；可学"读记录"与"做标记"两档基础（与 `WORLD-MACRO-001` §4 一致）。

### 3.6 关系边界（player-as-character 的内视角，**不**等于玩家真实偏好）
- 爱丽丝：信任度 baseline 50；紧张度 baseline 30。
- 尤吉欧：信任度 baseline 60；紧张度 baseline 15。
- 赛尔卡：信任度 baseline 50。
- 加利塔：信任度 baseline 50。
- 加斯夫特：信任度 baseline 40（他怀疑村务长会封锁）。

### 3.7 说话方式（以 `NAR-VOICE-001` §1 为唯一裁决）
- 多数"说话"以三种形态出现：选项标签（8–16 字）、记录本行文（第一人称、纯事实）、极少量出声台词。
- 数字优先于形容词；陈述句收尾，不用语气助词。
- 回答前先确认对方视线（行为特征）。
- 拒绝时给替代方案，不给理由。
- 口头禅：「记下了。」「对得上。」「我看见的是——」（每 Day ≤ 2 次）。
- 句长档位：常态 8–14 字；警觉 4–7 字；极端高压 2–4 字（唯一出现中断破折号）；唯一长句场合是朗读记录本 25–40 字。

## 4. 赛尔卡（selka）

### 4.1 宏观目标
- 在 Alice 被带走前 / 后，照顾书库与教会回廊里的孩子。
- 帮姐姐补全她在村里的判断。

### 4.2 恐惧
- **最怕**：成为姐姐被带走后村里"没人记得她做了多少"的那个人。
- 次怕：书库被锁后失去自己唯一的工作。
- 第三怕：玩家带来的"北境异常"会让书库被封。

### 4.3 价值观
1. 姐姐平安（**不在玩家面前直接说**，但行为上让步）。
2. 书库的可借阅性。
3. 不让村子里的孩子因为大人的争论而紧张。
4. 自己被需要。

### 4.4 秘密
- 她在 Alice 越界前**已经注意到书库"第 14.5 页"的痕迹**（纸张更厚、字迹不一样），但她没有上报给村务长。
- 她在 Act 2 后段会主动把这条信息告诉玩家，但要求"不要先告诉姐姐"。

### 4.5 能力边界
- **可做**：书库借阅、做神圣术标记、读/写记录、照顾孩子。
- **不可做**：独自越过静默线、独自面对整合骑士（**官方留白**，整合骑士带走的对象在原作中只有 Alice，Selka 不在带走名单上）。
- 神圣力消耗比 Alice 低 1 档；可维持 1 天的"标记不灭"。

### 4.6 关系边界
- 爱丽丝：信任度 baseline 95；紧张度 baseline 0（她对姐姐有保护欲，但**不表现为对玩家说**）。
- 见习记录员：信任度 baseline 50；紧张度 baseline 15。
- 尤吉欧：信任度 baseline 65。
- 加利塔：信任度 baseline 50。
- 加斯夫特：信任度 baseline 40（她对村务长把书库锁起来有怨气）。

### 4.7 说话方式
- 比 Alice 软半档，但**不撒娇**。
- 句长档位：常态 14–22 字；提到姐姐时变短到 6–10 字。
- 口头禅：「先告诉我谁要看。」「我还没归档。」「姐姐说过……」

### 4.8 会记住玩家
- 玩家是否在 N04 帮她把第 14.5 页的痕迹补归档（信任 +3）。
- 玩家是否在 Act 2 后期对"不要先告诉姐姐"的请求守约（信任 +5）。
- 玩家在 N10 越界时是否把记录本留给她（信任 +2）。

### 4.9 官方固定 vs 项目原创
- **官方固定**：Selka 是 Alice 的妹妹、教会书库帮手、对 Eugeo 的担心（Ep.3）。
- **项目原创**：内心恐惧排序、信任度 / 紧张度数值、句长档位、第 14.5 页痕迹的具体发现、Act 2 后段的"不要先告诉姐姐"请求。

## 5. 加利塔（garret · 北门巡守）

### 5.1 宏观目标
- 让北门巡查变成可交接的流程，而不是靠个人经验。
- 区分真正的异常和村民恐慌。

### 5.2 恐惧
- **最怕**：再发生一次他自己"听见过断风但没有足够证据上报"的事。
- 次怕：村务长为了稳定而压下不完整的异常记录。

### 5.3 价值观
1. 替年轻人挡住过早的处罚。
2. 流程比个人经验更可靠。
3. 村子的日常不能被一两次异常打乱。

### 5.4 秘密
- 他在 Act 1 之前已经**自己一次**听见过风声断约两息（与 N05 的玩家观察在节奏上吻合）；他没上报，因为"只一次不算"。

### 5.5 能力边界
- **可做**：北门值班、记路标、记风向、做交接记录、召集村民。
- **不可做**：越过静默线、面对整合骑士做判断（**官方留白**）。
- 体力档位与 Eugeo 相当；听力档位在 N06 触发时是**全村最高**。

### 5.6 关系边界
- 见习记录员：信任度 baseline 50；紧张度 baseline 15。
