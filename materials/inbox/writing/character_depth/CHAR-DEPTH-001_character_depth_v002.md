## 1. 桐人（kirito · 玩家）

### 1.0 显示名问题（v002 闭合）
- 玩家显示名 = **桐人**（用户 2026-08-06 明确）。
- 内部 id = `kirito`。
- 村民岗位 = **见习记录员**（C 类：项目原创补充；不增加新角色）。
- `uwCanonText.js` 与 `OpeningCinematic.vue` 中"见习记录员"是桐人在卢利特村的**村民岗位**渲染，**不**增加角色数量。
- v001 §3.0 的"显示名待用户裁决"问题在 v002 闭合。

### 1.1 宏观目标
- 与 Eugeo 一起完成 Gigas Cedar 天职（B：原作明确）。
- 在"规则"与"个人判断"之间形成自己的位置。
- 保护 Eugeo 和 Alice（**三人在一起**）。

### 1.2 恐惧
- **最怕**：因自己的沉默 / 隐瞒让同伴陷入危险。
- 次怕：自己的"既视感"被同伴追问而无答案。
- 第三怕：再次"既视感"出现时说出不该说的具体内容。

### 1.3 价值观
1. **事实的完整与可复核**。
2. **同伴能走回来**（高于"查清楚"）。
3. 自己的判断权不被别人抹掉。
4. 村里对他的评价（可牺牲）。
5. 规则的字面（最先被牺牲）。

### 1.4 秘密（B：原作·动画明确但当前官方网页摘要未覆盖）
- 桐人在童年阶段具有"既视感"——对动作 / 习惯的熟悉感，**未**给出具体来源解释。
- 在玩家面向文本中只表现为"我好像……见过这种——" + 立刻撤回；**不**出现 SAO / 现实世界 / 死亡游戏等具体关键词（剧透护栏）。

### 1.5 能力边界
- **可做**：挥斧、计数、读/写文本、做坐标、设撤退点、记录观察。
- **不可做**：战斗、越过静默线后独自返回、说出 SAO / 现实世界 / 死亡游戏等具体关键词。
- 神圣力不可习得；可学"读记录"与"做标记"两档基础。

### 1.6 关系边界
- 爱丽丝：信任度 baseline 50；紧张度 baseline 30。
- 尤吉欧：信任度 baseline 60；紧张度 baseline 15。
- 赛尔卡：信任度 baseline 50。
- 加利塔：信任度 baseline 50。
- 加斯夫特：信任度 baseline 40。
- 整合骑士：N/A（敬畏 + 不确定；N08 之前不出现）。

### 1.7 说话方式（以 `NAR-VOICE-001` §1 为唯一裁决；按桐人身份调整）
- 多数"说话"以三种形态出现：选项标签、记录本行文、极少量出声台词。
- 数字优先于形容词；陈述句收尾，不用语气助词。
- 句长档位：常态 8–14 字；警觉 4–7 字；极端高压 2–4 字（出现中断破折号）；唯一长句场合是朗读记录本 25–40 字。
- 口头禅：「记下了。」「对得上。」「我看见的是——」（每 Day ≤ 2 次）。
- **既视感表达**：在 N05 / N06 高压瞬间出现"这个动作我——" + 立刻撤回"记时间"。

### 1.8 会记住玩家什么
- **N/A**（玩家自身即桐人；不需"会记住玩家什么"）。

### 1.9 A + B + C 三类划分
- **A（官方明确）**：桐人在卢利特村与 Eugeo 同为伐木手；童年与 Alice 关系亲近；Gigas Cedar 是 Calling；与 Eugeo 一起前往 End Mountains 洞窟；听 Eugeo 提到 Blue Rose Sword。

## 2. 尤吉欧（eugeo）

### 2.1 宏观目标
- 完成 Gigas Cedar 天职（A：官方 Ep.1）。
- 在"天职 / 朋友 / 自我判断"之间维持平衡。
- **三人在一起**（高于任务、高于安全）。

### 2.2 恐惧
- **最怕**：因为自己太稳，别人只好一个人去。
- 次怕：自己的谨慎变成怯懦的借口。
- 第三怕：巨神树倒了之后要去哪里（B 类原作明确但未展开）。

### 2.3 价值观
1. 三个人在一起（A：核心三人；B：原作明确）。
2. 明天还能继续。
3. 同行者的知情权。
4. 天职按规矩完成。
5. 他自己想要的东西（最末项）。

### 2.4 秘密
- 他长期持有从 North Cave 找到的 Blue Rose Sword（A：官方 Ep.3；B：原作明确）。
- 童年阶段 Alice / 桐人**不知道**此剑；Eugeo 自己也未必每次都带在身上。
- Pre-Capture 阶段**不**出现 Blue Rose Sword 实体（B 类原作保护）。

### 2.5 能力边界
- **可做**：挥斧、计数、听年轮、记风向、记撤退点、与 Alice 分工。
- **不可做**：战斗级剑术、Blue Rose Sword（童年阶段不出现）、越过静默线后独自返回。

### 2.6 关系边界

- 加斯夫特：信任度 baseline 40。

### 2.7 说话方式（以 `NAR-VOICE-001` §3 为唯一裁决）
- 先共情、后条件；从不用"但是"开头拒绝。
- 软化词密度最高：也许 / 大概 / 我想 / 说实话 / 至少。
- 比喻来自木头、风、霜、年轮、季节。
- 主动起话头、负责填补沉默。
- 句长档位：常态 20–30 字；犹豫时膨胀到 35–50 字；真危险时塌到 5–9 字。
- 口头禅：「我也……」「先……再……」「说实话，」「明天还要来。」

### 3.1 宏观目标
