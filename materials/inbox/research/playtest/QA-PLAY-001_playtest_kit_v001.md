## 1. 试玩协议

| 项 | 约定 |
|---|---|
| 目标人数 | 3 名未参与开发的人 |
| 前置条件 | 每人从"新游戏"开始，不做任何玩法预解释 |
| 录制要求 | 屏幕录制，尽量含鼠标/触控轨迹；声音可选 |
| 隐私 | 可用 `player01` 替代真名；录音前必须获得同意；不录制私人通知/账号画面 |
| 时长上限 | 每人 ≤ 90 分钟，含开场、试玩、访谈 |
| 数据去向 | 仅用于本游戏开发迭代，不外传 |

**主持人的三条红线**
1. 玩家卡住时，先记时间点，至少等 60 秒再决定是否给提示。
2. 给了提示必须记录：时间点 + 原话。宁可多记，不可漏记。
3. 全程不要解释"设计意图"，只观察和记录。

## 2. 开场脚本（逐字念，不发挥）

> 谢谢你今天来帮我试玩。这是一款还在开发中的游戏，今天你玩的版本可能会有没做完的地方。
> 请你像平时玩新游戏一样，从"新游戏"开始。我不会提前告诉你玩法，你想怎么玩就怎么玩。
> 我会录下你的屏幕，可能还有声音。如果你中途觉得不舒服，随时可以叫停，录下来的东西我会删掉。
> 这份同意书（递出）请看一下，没问题就签字。签完我们就开始。

## 3. 同意书（一式两份，玩家一份，项目留档一份）

```md
# 试玩同意书

我，________________（姓名或代号），同意参加《边境回声》试玩测试。

我已知晓：
- 我的屏幕画面将被录制，声音录制为【可选：同意 / 不同意】。
- 录制内容仅用于游戏开发迭代，不会公开传播。
- 我可以在任何时刻要求停止并删除录制内容。
- 我的真实姓名不会出现在任何交付物中。

签名：______________  日期：____________
```

## 5. 结束访谈（5 个固定问题，逐字问，不做引导）

1. 你现在觉得，你在游戏里的目标是什么？
2. 随便说一种你做过的行动的"代价"。
3. 随便说一种你做过的行动的"收益"。
4. 爱丽丝和尤吉欧，你觉得谁更在意什么？
5. 你现在最想知道的悬念是什么？

（记录每个回答的原话；玩家答"不知道"也算答案，照记。）
