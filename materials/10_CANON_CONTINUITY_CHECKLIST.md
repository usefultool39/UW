# 正典连续性检查表：Pre-Capture

每次新增剧情、素材、角色或 AI 对话前，逐项检查。

## 事实层

- [ ] 是否发生在爱丽丝被带走之前？
- [ ] 是否符合露茵村童年阶段？
- [ ] 是否保持爱丽丝、尤吉欧、桐人的基本关系？
- [ ] 是否保持基家斯西达天职和尤吉欧的责任压力？
- [ ] 是否保持禁忌目录与尽头山脉的边界意义？
- [ ] 是否提前使用了后期整合骑士爱丽丝、战争、中央大教堂或黑剑士能力？

## 可玩层

- [ ] 玩家是否有明确目标，而不是只阅读背景？
- [ ] 选择是否改变线索、关系、记忆或临场表达？
- [ ] 选择是否仍然允许固定终点成立？
- [ ] 事件是否至少包含一个可观察的行动结果？
- [ ] 是否避免把所有分支都写成相同的二选一文本？

## 角色层

- [ ] 爱丽丝是否有主动欲望，而不是等待被推动？
- [ ] 尤吉欧是否有责任判断，而不是单纯胆怯或陪衬？
- [ ] 桐人是否保留童年阶段的不成熟？
- [ ] 支持 NPC 是否拥有自己的信息、目标和限制？
- [ ] 每个新增 NPC 是否明确“他知道什么、害怕什么、不会说什么”？

## 交付层

- [ ] 是否有来源等级：正典固定 / 正典留白 / 项目原创？
- [ ] 是否写入事件 ID、前置条件、结果和后续回响？
- [ ] 是否更新 `REQUESTS.csv` 或对应 sidecar？
- [ ] 是否有至少一条后端连续性测试？
- [ ] 是否需要真实玩家盲测或素材审查？
