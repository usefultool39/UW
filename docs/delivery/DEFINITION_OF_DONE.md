# Definition of Done

- **状态**：Current

## 所有改动

- [ ] 验收满足且未扩大范围。
- [ ] 代码/内容遵守架构边界，无明显重复和死代码。
- [ ] 新行为有自动测试，或记录不能自动化的原因和手测证据。
- [ ] 后端测试、前端 build、相关 E2E 通过。
- [ ] `git diff --check` 通过；无密钥、运行记忆、构建产物。
- [ ] 玩家可见变化更新 `CHANGELOG.md`。
- [ ] 当前能力/下一阶段/架构变化更新权威文档。
- [ ] PR 写明风险和回滚方式。

## 玩法/内容

- [ ] 玩家知道为什么可用/不可用，以及行动后发生什么。
- [ ] 时间、资源、flag、关系、记忆由后端结算。
- [ ] 失败路径不部分写状态。
- [ ] 新内容从正常路径可到达，不依赖开发按钮。
- [ ] scripted 模式无 API 可完成。
- [ ] 相关时验证新游戏和已有存档。

## UI

- [ ] 1440×900 桌面基线可用，窄窗口不遮挡关键流程。
- [ ] modal 可关闭，busy/错误/成功有反馈。
- [ ] 无新增控制台错误；UI 变化有截图或 E2E 证据。

## API/存档

- [ ] DTO 和错误码有兼容测试。
- [ ] 新字段有默认值；破坏性变化有迁移与 ADR。
- [ ] 失败不会破坏当前状态。
