# 下一阶段：三日纵切片质量收束

- **状态**：Current / 唯一可执行计划
- **阶段代号**：M1 Vertical Slice Quality
- **目标版本**：`0.4.0-preview.1`

## 目标

不扩写大段新剧情，让 Day 1–3 达到“容易上手、行动有判断、关系有回响、异常有升级”的外部试玩标准。

## 成功指标

1. 3 名首次玩家中至少 2 名无需提示完成 Day 1。
2. 60 秒内完成第一次有效互动。
3. 玩家能解释一种资源代价和一种活动收益。
4. Day 1–3 无 P0/P1；存档/重开不串周目。
5. 每名玩家看到至少一次早期选择的后续回响。
6. CI pytest、build、E2E 全绿。

## 工作包

### WP-1 首次玩家路径（P0）
观察全新 Day 1 到第一次休息；合并重复提示，统一主目标/推荐下一步/锁定原因；错误提供恢复建议。验收：按 PLAYTEST 盲测并记录用时和卡点。

### WP-2 关系后果闭环（P0）
选两项 Day 1 选择，明确 Day 2/3 回响；结果和档案解释变化原因。验收：后端测试 + 至少一个 E2E 回响。

### WP-3 活动架构收束（P0）
前端活动 ID、panel、提示和结果字段进入注册表；后端资源/flag 规划与校验抽纯函数，Session 保留提交、关系和记忆。暂不大拆 Phaser scene 或 npc_intents。

### WP-4 质量门与候选版（P1）
CI 覆盖 backend/build/E2E；清理死链接和过时入口；干净环境验证 macOS 启动与存档兼容。

## 不做

不新增大地图/多人/账号；不切主客户端到 Cocos；不要求 API；不一次性重写巨型文件；不以更多文字代替首次玩家测试。
