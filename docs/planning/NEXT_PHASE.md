# 下一阶段：M2 素材风格锁定与首次玩家盲测

- **状态**：Current / 唯一可执行计划
- **阶段代号**：M2 Style Lock & Blind Playtest
- **目标版本**：`0.4.0-preview.2`
- **前置基线**：`0.4.0-preview.1` 候选工作区（说明见 `docs/delivery/RELEASE_0.4.0-preview.1.md`）

## 目标

不再凭感觉继续堆功能。先用一小组可替换素材锁定原创视觉/听觉方向，再让真实首次玩家从新游戏完成 Day 1，使用数据决定下一轮 UI、节奏和内容改动。

## 成功指标

1. 完成 1 份批准的视觉方向板、1 张开场关键图、3 名核心人物统一肖像方向和 1 组 UI 图标样张。
2. 完成村庄清晨 BGM、细雨环境声、基础 UI/活动反馈音样张，并通过无爆音循环检查。
3. 3 名首次玩家中至少 2 名无需口头提示完成 Day 1；60 秒内完成第一次有效互动。
4. 至少 2 名玩家能复述一种行动代价、一种奖励和一次关系回响。
5. scripted 离线基线、存档兼容、backend tests、frontend unit/build、完整 E2E 保持全绿。

## 工作包

### M2-WP1 素材风格锁定（P0）

- 从 `materials/01_REQUEST_CATALOG.md` 只先执行“首批 6 项”，不要一次生产全部资产。
- 所有原始文件进入 `materials/inbox/`，附同名 sidecar 元数据；通过评审后才进入 `materials/approved/`。
- 禁止直接复制官方截图、角色定妆、商标 UI 或来源不清素材；先做原创化方向样张，再扩量。

### M2-WP2 真实首次玩家盲测（P0）

- 按 `docs/delivery/PLAYTEST.md` 记录 3 次完整 Day 1：首次有效互动时间、卡点、误点、是否理解代价/收益、是否发现关系回响。
- 不现场教学；测试结束后再访谈。
- 只修复重复出现或阻塞目标的 P0/P1，不以单个个人偏好触发大重写。

### M2-WP3 素材接入最小切片（P1）

- 第一轮只接入已批准的开场图、核心肖像、UI 图标和音频样张。
- 运行时素材进入 `frontend/public/assets/game/` 或明确的新子目录；原始源文件继续留在 `materials/approved/`。
- 图片、音频、许可证、提示词和来源必须能从 manifest 追溯。

### M2-WP4 候选版质量门（P1）

- 干净 macOS 环境验证启动；新存档导出/导入、旧存档加载、scripted 无网络运行。
- 通过后再考虑 commit 与 annotated tag；本阶段不自动 push。

## 不做

不一次性重画全地图；不先做完整角色动画；不新增大剧情线；不要求 agent API 才能试玩；不把 AI 生成素材直接复制进运行时目录而绕过来源与验收流程。
