# 下一阶段

下一阶段只做三件事，不新增旁支计划。

## 先完成体验收束

- 统一桐人身份和 Pre-Capture 首屏文案。
- 合并系统按钮，移除重复常驻教学，确保主目标、地图和附近互动层级清楚。
- 在 1440×900 与 390×844 检查首屏、移动、互动、选择和结果反馈。

## 再完成素材最小闭环

- 选一张场景插图试接事件面板，验证安全区和裁切。
- 用一张代表性村庄地图切片验证地标、碰撞、遮挡和角色比例。
- 返工三位核心角色的统一动作样张；不先扩展支持 NPC。
- 重做抓捕终点关键图，确保事件与人物关系正确。
- 对 SFX 逐文件补 sidecar、测量和试听结论。

## 最后做发布验证

- 从新游戏连续完成全部关键节点并验证终点不可继续推进。
- 运行 `scripts/release.sh`，修复 E2E 与素材门禁。
- 招募三名陌生玩家完成盲测，只修复最高频阻塞。
- 完成 IP/素材权利评估后，才能决定公开发布或原创化改写。

## 明确不做

- 不扩写爱丽丝被带走后的剧情。
- 不恢复旧 Day 长线或月度路线开发。
- 不批量生成全角色、全地图、全配音。
- 不用新文档复制当前状态和下一步。
