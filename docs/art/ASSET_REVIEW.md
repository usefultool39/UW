# 素材审查与制作清单

- **对应版本**：`0.5.0`
- **审核日期**：2026-08-07
- **结论**：现有素材足以支撑内部原型，但正式地图、统一角色动作、抓捕终点和完整 SFX 仍未达到发布标准。

## 1. 状态定义

- **可用**：来源和技术条件基本清楚，可继续用于内部版本。
- **可试接**：文件可加载，但必须通过真实游戏中的比例、裁切、安全区和风格检查。
- **仅原型**：只能证明技术流程，不代表正式美术完成。
- **返工**：内容、风格、完整性或来源不满足当前目标。

## 2. 当前结论

| 素材 | 判定 | 当前用途 | 修改意见 |
|---|---|---|---|
| 村庄开场图 | 可用 | 开场和短提示背景 | 补移动端独立裁切；停用来源不清的旧电视感背景 |
| 核心人物肖像 | 可用 | 对话面板临时使用 | 统一服装、线稿与光源；补紧张、坚定、告别表情 |
| 核心 UI 图标 | 可用 | 资源、关系、线索和状态 | 先检查 24px 可读性；新图标保持同一线宽和留白 |
| 村庄清晨音乐、细雨 | 可用 | 当前离线声景 | 补淡入淡出、循环点和移动端自动播放提示 |
| 书库、巨神树、炉火、北门等场景插图 | 可试接 | 事件卡、互动面板或过场 | 标注左右文字安全区、人物站位和移动端裁切；不能当可走地图 |
| 三位核心角色动作表 | 仅原型 | 验证加载、帧数和锚点 | 比例偏细长、动作差异弱、与场景风格不统一，重做后再接 runtime |
| 分层村庄地图 | 仅原型 | 保留碰撞与图层技术合同 | 建筑道路重复、地标叙事弱；需统一正交视角和最终贴图 |
| 村庄概念大图 | 方向参考 | 色彩和地标密度参考 | 透视过强且有可见网格，不能直接作为 Phaser 可走地图 |
| 抓捕终点关键图 | 返工 | 不接入终点 | 旧画面不是村中宣罪、告别和带走，人物与事件均不完整 |
| 支持 NPC 样张 | 返工 | 不接 runtime | 缺左右方向、完整动画、统一比例和 sidecar |
| UI/环境 SFX 候选 | 返工后可复用 | 先试听与补元数据 | 每个文件补来源、用途、响度、峰值和 loop/one-shot 判定 |
| VFX sheet | 仅原型 | 功能验证 | 补透明边缘、帧节奏、遮挡和低性能模式检查 |

具体机器文件名和历史修订只在 `materials/MANIFEST.csv`、`materials/REQUESTS.csv` 与素材 sidecar 中追溯，不在主文档堆叠版本号。

## 3. 现在可以使用

1. 村庄开场图。
2. 现有核心肖像和 UI 图标。
3. 村庄清晨音乐与细雨环境声。
4. 选择一张场景插图试接事件面板。
5. 角色动作表和分层地图只保留作技术参考，不升级为正式美术。

## 4. 下一批必须制作

### 可走村庄地图

- 主画布建议 3024×1792，正交或轻俯视，无透视地平线和可见网格。
- 分为地形、水、道路、建筑、植被、遮挡、前景、光照和天气层。
- collision、walkable、interaction 数据必须与地标一致。
- 教会书库、巨神树、三人住处、村广场和北门必须一眼可辨。
- 先交一张 1440×900 游戏内截图验收，不先批量生产整套。

### 核心角色

- 桐人、尤吉欧、爱丽丝使用统一帧格与人体比例。
- 四方向；idle 至少 2 帧、walk 至少 6 帧、interact 至少 4 帧。
- 桐人、尤吉欧的伐木和爱丽丝送餐/施救要有独立轮廓。
- 三人的脚底锚点、落地阴影、碰撞盒和光照一致。

### 抓捕终点

- 必须同时出现卢利特村、整合骑士、爱丽丝、家人、桐人和尤吉欧。
- 事件顺序是公开宣罪、告别、被带走，不用树洞或魔法门替代。
- 桌面和移动端分别构图，预留对白与按钮安全区。
- 先审黑白构图和人物关系，再进入上色精修。

### UI 与场景

- 场景插图补文字安全区、人物站位层和轻量景深层。
- UI 只补当前流程确实缺少的图标，不批量生成几十种状态变体。
- 所有新图标先验收 24px，再输出较大尺寸。

### 音频

- 边界调查与关系日常各一组可循环 BGM。
- 森林正常/静默两条等长 ambience，以切换表达异常。
- 最小 SFX：确认、取消、失败、线索、关系变化、脚步、翻书、门、抓捕静默。
- 每个文件记录 sample rate、bit depth、LUFS、true peak、循环点和许可。

## 5. 统一命名

玩家界面、文档和日常沟通使用“村庄地图、桐人动作、抓捕关键图”等可读名称。新批准的 runtime 文件使用稳定短名：

```text
runtime/maps/rulid-village/
runtime/characters/kirito.png
runtime/scenes/church-library.jpg
runtime/audio/boundary-investigation.ogg
```

请求 ID 与历史修订只属于素材台账和 sidecar。不要再创建 `final_final`、日期副本或把素材版本号放进玩家界面。

## 6. 进入 runtime 的证据

- 来源与权利说明完整。
- 技术检查通过。
- 人工内容和正典检查通过。
- 1440×900 与 390×844 游戏内截图通过。
- 无文字遮挡、锚点漂移、可走区错位、明显水印或风格跳变。
- `MANIFEST.csv` 的 source、runtime、hash、审核人和时间完整。
