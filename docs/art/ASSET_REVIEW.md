# 素材审查与缺口清单

- **审核日期**：2026-08-07

- **结论**：现有素材足以支撑内部原型和 UI 收束，但不足以把地图、人物动作和抓捕终点称为正式美术完成。

## 状态定义

- **可用**：来源和技术条件基本清楚，可继续在内部版本使用。
- **可试接**：技术可用，但必须先在真实界面中验证比例、裁切、文字安全区和风格。
- **仅原型**：能说明功能，不代表最终美术。
- **返工**：方向、完整性、来源或内容不满足当前目标。

## 下一批必须制作的素材

### 可走村庄地图

- 3024×1792 主画布，正交或轻俯视，不出现透视地平线和可见网格。
- 地形、水、道路、建筑、植被、遮挡、前景、光照、天气九层。
- collision、walkable、interaction 三类数据与实际地标一致。
- 教会书库、巨神树、三人住处、村广场、北门必须一眼可辨。
- 先交一个 1440×900 游戏内截图，不先批量生成整套。

### 核心角色

- 桐人、爱丽丝、尤吉欧统一 64×96 或 96×128 帧格。
- 四方向；idle 至少 2 帧、walk 至少 6 帧、interact 至少 4 帧。
- 桐人、尤吉欧的伐木动作和爱丽丝递交午餐/施救动作需要独立轮廓。
- 角色落地阴影、脚底锚点和碰撞盒必须一致。

### 抓捕终点

- 场景必须同时包含：卢利特村、整合骑士、爱丽丝、家人、桐人和尤吉欧。
- 情绪顺序是公开宣罪 → 告别 → 被带走，不使用魔法门替代事件。
- 桌面和移动端分别构图，预留对白和按钮安全区。

### 场景与 UI

- 场景插图补充文字安全区标注、角色站位层和轻量景深层。
- UI 只补真正缺少的图标，不再一次生成几十个状态变体。
- 所有图标先验收 24px，再输出 48px 与 96px。

### 音频

- 边界调查与关系日常各一组可循环 BGM。
- 森林正常/静默两条等长 ambience，用切换而非突然停声表达异常。
- 最小 SFX：确认、取消、失败、线索、关系变化、脚步、翻书、门、抓捕静默。
- 每个文件记录 sample rate、bit depth、LUFS、true peak、循环点和许可。

## 新命名规则

玩家界面、文档标题和日常沟通只使用“村庄地图、桐人动作、抓捕关键图”这类可读名称。请求 ID 仅用于台账；修订由 Git 提交、hash 和评审记录追溯，不再继续制造 `v007_final_final2` 一类文件名。

旧文件名为了历史追溯暂不批量改名；新批准的 runtime 文件使用稳定短名，例如：

```text
runtime/maps/rulid-village/
runtime/characters/kirito.png
runtime/scenes/church-library.jpg
runtime/audio/boundary-investigation.ogg
```
