# 美术方向与地图细粒度计划

更新日期：2026-05-13  
状态：计划已定，正式资产暂缓制作；当前优先把地图框架比例调细。

## 目标

把当前地图从“可读的程序化 tilemap”推进到“能承接正式美术资产的 RPG 场景框架”。

短期不急着大批量画资产，先把比例、层级、可走逻辑和角色尺度调顺。之后无论接 2D 手绘、高清像素，还是 2.5D 等距，都不会推倒重来。

## 推荐美术方向

第一章 Demo 推荐走：**细颗粒 2D 俯视 / 高清像素混合风格**。

原因：

- 当前玩法是俯视移动、点击调查、NPC 站位，2D 俯视最贴合现有 Phaser 框架。
- 高清像素或细颗粒手绘都能让道路、水岸、树冠、建筑边界清楚，玩家能自然判断哪里可走。
- 不需要马上做复杂 3D、骨骼动画或等距遮挡系统，风险更低。

暂不推荐立即做完整 2.5D 等距。等距更漂亮，但会立刻引入角色遮挡、建筑层级、点击格映射和路径视觉偏移问题，当前阶段会拖慢 Day 1/Day 2 体验打磨。

## 比例规范

当前框架先采用以下比例：

- 逻辑 tile：仍然是后端权威网格，用于寻路、碰撞、POI、NPC 日程。
- 渲染 tile：从 `34px` 下调到 `28px`，让地图颗粒更细。
- 默认镜头：从近距离展示改为略微拉远，桌面首屏能看到更多道路、水域和功能区关系。
- 角色高度：玩家约 `54px`，NPC 约 `50px`，不再像大 token 压在地图上。
- 交互标记：只作为世界内提示，不承担建筑或地形本体。

后续正式资产建议：

- 地表基础纹理：每 tile 28px 或 32px 对齐。
- 角色 sprite：站立高度约 1.6-1.9 个 tile。
- 门、桌、树干、路牌：至少保留一个可走 approach tile。
- 大建筑和巨树：可以跨多个 tile，但必须有独立遮挡层和可交互点。

## 地图层级

正式地图应拆成这些层：

1. **Ground**：草地、泥地、石路、水边浅滩。
2. **Road**：明确可走的主路、支路、门前小径。
3. **Water**：水面底图、岸线、波纹动画。
4. **Obstacle**：树、岩石、篱笆、建筑实体，不可走。
5. **Occlusion**：树冠、屋檐等可遮挡角色的上层。
6. **Landmark**：书库、小屋、巨树、北境边门等地标。
7. **Interact**：调查点、任务点、入口提示、区域反馈。
8. **Debug**：可走层、scene zone、NPC schedule，仅开发模式显示。

原则：玩家看到的可走道路，必须和后端 walkable 数据一致；NPC 视觉落点必须从 schedule 或 POI 的可走 tile 派生。

## 资产清单

第一批正式资产建议只做露茵村 Day 1/Day 2 必需内容：

- 草地基础 6-8 张变体。
- 泥路/石路：直线、弯道、T 字、十字、路边过渡。
- 水域：深水、浅水、水岸内角/外角、细波纹。
- 树林：单棵树、树冠块、森林边缘、树影。
- 障碍：岩石、木栅、封锁边界符号。
- 建筑：小屋、书库、门口、窗光。
- 地标：古誓树、北境边门、村道广场。
- 角色：玩家、艾琳、尤里的 idle/walk 四方向基础动画。
- UI 世界标记：线索光点、入口提示、不可达反馈、目标方向箭头。

## 制作顺序

第一阶段：框架细化，已开始执行。

- 下调 tile 渲染尺寸。
- 缩小角色和交互提示。
- 确保 NPC / POI / 事件显示吸附到可走格。
- 给锁区入口增加 approach tile。
- 保留导航调试层。

第二阶段：替换地表和道路。

- 先做草地、道路、水岸三类 tileset。
- 保持现有 JSON 地图不变，只替换渲染器。
- 验收标准：不看文字也能分辨主路、水域、森林和广场。

第三阶段：地标和遮挡。

- 替换书库、小屋、古誓树、北境边门。
- 增加 Occlusion 层，让树冠/屋檐能遮住角色一部分。
- 验收标准：角色站在建筑或树旁不再像浮在图上。

第四阶段：角色动画。

- idle 四方向。
- walk 四方向，每方向 4-6 帧。
- 对话或事件时增加轻微朝向和停顿。
- 验收标准：移动时不再是静态 token 滑动。

第五阶段：氛围和 polish。

- 水面循环波纹。
- 树叶轻微摆动。
- 雨天水面和地面湿润差异。
- 傍晚窗光、夜间色调。

- `frontend/public/assets/game/characters/`

命名：

- `tiles_grass_01.png`
- `tiles_road_corner_ne.png`
- `water_shore_inner_ne.png`
- `landmark_library_day.png`
- `char_airin_walk_down_01.png`
- `vfx_clue_pulse_01.png`

当前第一版 manifest：

- `frontend/public/assets/game/tilesets/luin_village_v1.json`

它先定义地形语义、颜色、可走性和角色 token 路径。正式 tile 图片接入后，Vue/Phaser 和 Cocos 都应优先读 manifest；没有图片时继续回退到程序化 tile。

## 验收要求

每轮美术替换都要检查：

- 桌面 `1440x900` 和手机 `390x844` 截图。
- Canvas 非空。
- 核心 UI 不重叠。
- NPC 不在水上、树上、锁区里。
- 玩家能靠视觉判断道路和不可走区域。
- `npm.cmd run build` 通过。
- `npm.cmd run test:e2e` 通过。
