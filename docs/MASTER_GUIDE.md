# 第一章：项目是什么

## 1.1 一句话定义

UW 是一个单人 2D 叙事 RPG。玩家以桐人的视角，在卢利特村与尤吉欧、爱丽丝共同生活、劳动、调查并做出选择。选择可以改变关系、记忆、准备方式、对话和告别反馈，但不改写"爱丽丝最终被带走"的固定终点。

## 1.2 设计哲学

叙事骨架已经扎实，但**玩法层必须让玩家"想再多玩一天"**。在序章框架内填充足够丰富的日常玩法（采集、烹饪、钓鱼、收集、任务），使 15-25 分钟的主线体验之外仍有可重复的乐趣。

**参考游戏**：
- **星露谷物语**：日常劳动有乐趣和产出，时间管理是策略
- **摩尔庄园/奥比岛**：生活感、收集感、家园归属感
- **梦幻西游**：成长和经济循环，关系系统可见可感
- **夏日狂想曲**：关系管理的可见反馈，时间分配的紧迫感
- **传奇**：简单直接的成长多巴胺

## 1.3 玩家承诺

玩家进入游戏后应迅速理解：

- **我是谁**：桐人，卢利特村的见习记录员（村民岗位）
- **我在哪里**：卢利特村
- **我和谁在一起**：尤吉欧、爱丽丝、赛尔卡
- **我现在要做什么**：前往巨神树并与两人会合
- **我每天还能做什么**：砍树、读书、采药、钓鱼、巡查、帮村民做事
- **我的选择有什么意义**：影响关系、记忆、准备和后续回应
- **我的劳动有什么意义**：产出材料、提升熟练度、解锁新活动
- **故事会走向哪里**：越界、返村、宣罪、告别，最终爱丽丝被带走

新玩家应在 60 秒内完成第一次有效互动。

# 第二章：世界观与设定

## 2.1 三栏分类体系

所有设定按三类标注，贯穿全部写作：

| 分类 | 含义 | 约束 |
|---|---|---|
| **A** | 官方明确 | 不可改写 |
| **B** | 原作·动画明确但官方网页摘要未覆盖 | 不可改写，表现方式可原创 |
| **C** | 项目原创补充 | 不得替代 A/B；可改但不进关键节点表 |

## 2.2 世界结构

```
人界（Human Empire）
├── 中央大教堂 ── Pre-Capture 不可进入、不可详细描写
│   ├── 最高司祭 ── 不可见
│   ├── 元老院 ── 不可见
│   └── 整合骑士团 ── 仅 N08/N09/N10 在村中出现
├── 禁忌目录 ── 世界规则，非普通法律
├── 卢利特村 ── 玩家在此出生成长
│   ├── 村务长（加斯夫特代行 / Alice 父亲）
│   ├── 北门巡守（加利塔）
│   ├── 神圣术见习（爱丽丝 / 赛尔卡）
│   ├── 巨神树伐木手（桐人 / 尤吉欧）
│   └── 见习记录员（桐人的村民岗位）
├── 尽头山脉
│   ├── 洞窟 ── N05/N06 舞台
│   └── 边界线 ── 爱丽丝越界处
└── 暗黑界 ── 远方存在，不可进入
```

## 2.3 关键设定

- **禁忌目录**：世界规则。玩家可见条目极少（"北门不越过"等）。村民敬畏但不完全理解 `[A]`
- **神圣术**：治疗、读写记录、做标记。桐人不会学到战斗级术式；可学"读记录"与"做标记"两档基础 `[C]`
- **整合骑士**：仅 N08（宣告）、N09（告别）、N10（带走）在村中出现。N10 前不出现 Synthesis 编号、神器名字 `[B+C]`
- **巨神树**：基加斯西达，桐人和尤吉欧的天职（Calling）`[A]`

## 2.4 资源体系

| 资源 | 玩法用途 |
|---|---|
| 体力 | 所有活动消耗；食物可恢复 |
| 生命（天命 HP） | 巡查/危险消耗；夜间恢复 |
| 神圣力（MP） | 神圣术消耗；可恢复 |
| 食物 | 可持有、可使用恢复体力；烹饪产出 |
| 木材 | 砍树产出，可用于制作/修缮 |
| 草药 | 西侧田野采集，制作恢复道具（0.6.0 新增） |
| 鱼类 | 南湖垂钓，食材/收藏（0.6.0 新增 P1） |
| 刻印素材 | 书库/巡查获得，手抄祈句卷轴（0.6.0 新增） |

> **不可写**：任何"金币/通货"暴露给玩家；任何"等级/经验值"暴露。

## 2.5 剧透护栏

N10 之前**任何人不得说出、不得暗示**：

1. 爱丽丝未来的整合骑士身份、金木樨之剑、中央大圣堂内部政治
2. 尤吉欧的青蔷薇之剑（只能作为北方洞窟传说轻轻带过）
3. 桐人的现实世界记忆（SAO 相关），只能表现为说不清来源的既视感
4. 元老院的具体人名、席位、内部流程
5. 整合骑士的 Synthesis 编号

## 3.2 桐人（玩家）

- **目标**：完成天职；在规则与个人判断之间形成位置；保护尤吉欧和爱丽丝
- **恐惧**：最怕因沉默/隐瞒让同伴陷入危险；次怕既视感被追问无答案
- **价值观**：事实完整可复核 > 同伴能走回来 > 自己的判断权 > 村里评价 > 规则字面
- **秘密**：童年阶段有"既视感"，不给出具体来源 `[B]`
- **能力**：可做（挥斧、计数、读写、做坐标、设撤退点、记录观察）；不可做（战斗、越过静默线后独自返回、说出 SAO/现实世界/死亡游戏）
- **关系基线**：爱丽丝信任50/紧张30；尤吉欧信任60/紧张15
- **说话方式**：选项标签（8-16字）、记录本行文（纯事实）、极少量出声台词。句长：常态8-14字；警觉4-7字；极端2-4字。口头禅：「记下了。」「对得上。」「我看见的是--」
- **既视感**：N05/N06 高压时"这个动作我--"+立刻撤回"记时间"

## 3.3 尤吉欧

- **目标**：完成天职；三人在一起
- **恐惧**：最怕因为自己太稳别人只好一个人去；次怕谨慎变怯懦
- **价值观**：三个人在一起 > 明天还能继续 > 同行者知情权 > 天职按规矩 > 自己想要的
- **秘密**：长期持有 Blue Rose Sword（Pre-Capture 不出现）`[B]`
- **关系基线**：爱丽丝信任85/紧张5；桐人信任80/紧张10
- **说话方式**：先共情后条件；从不用"但是"开头。软化词最多（也许/大概/我想）。比喻来自木头、风、霜、年轮。句长：常态20-30字；犹豫35-50字；危险5-9字。口头禅：「我也……」「先……再……」「说实话，」「明天还要来。」

## 3.4 爱丽丝

- **目标**：在"遵守规则"与"亲眼确认事实"之间做出不后悔的判断；施援受伤者
- **恐惧**：最怕按规则做了正确的事代价却落到别人身上；次怕成为"最后知道的人"
- **价值观**：所有人都能回来 > 记录完整可复核 > 规则必须能被解释 > 自己的判断被采纳 > 自己被喜欢
- **秘密**：N03 后已决定确认洞窟传说；N05 主动选择施援；N10 接受带走 `[B]`
- **能力**：可做（神圣术标记、读写记录、基础治疗、送餐、组织准备、施援）；不可做（战斗级术式、独自对抗骑士、永久反抗带走）
- **关系基线**：尤吉欧信任70/紧张10；桐人信任50/紧张30
- **说话方式**：完整句主谓宾齐全；先条件后结论；用"我们"承担、用"你"要求。句长：常态18-26字；极限3-5字。口头禅：「我还没确认。」「先把这一条写下来。」「你听完再回答。」

## 3.5 赛尔卡

- Alice 的妹妹，教会书库帮手
- 恐惧：成为"没人记得她做了多少"的人
- 说话比 Alice 软半档但不撒娇。句长14-22字；提到姐姐时6-10字
- 口头禅：「先告诉我谁要看。」「我还没归档。」「姐姐说过……」
- 0.6.0：可作为采药教学 NPC；接受萤火虫礼物增加好感

## 3.6 加利塔

- 北门巡守，C 类原创
- 恐惧：再发生"自己听见但没上报"的事
- 说话直接稳重。句长16-22字；警告8-12字
- 口头禅：「听风要听三息。」「记下时间。」「我去叫人。」
- 0.6.0：可教授巡查道具组合使用

## 3.7 加斯夫特

- 村务长代行，C 类原创
- 恐惧：上报太早让外部权力介入，把孩子们从日常里带走
- 说话慢、克制、像在称量每个词。句长22-30字
- 口头禅：「先让流程走完。」「谁在场？签字了吗？」
- 0.6.0：可发布公告柱任务

## 3.8 整合骑士（仅 N08/N09/N10）

- 1 名主骑士（Deusolbert Synthesis Seven）+ 2 名次级骑士
- 不与玩家对话超过 3 句；不透露 Synthesis 编号、神器名字
- 说话短、慢、"标准提醒"句式。单句<=18字
- 口头禅：「你已越过规则边界。」「跟我们回去。」

## 5.4 玩家介入模型

| 层级 | 内容 |

| 固定（不可改） | 三人童年关系、Calling、禁忌目录、爱丽丝越界、返回、被带走（F1-F20） |

- 三个 choice 都不能阻止骑士宣告（N08）

# 第八章：技术架构

## 8.1 架构

```
玩家 -> Vue UI <--> Phaser 地图
                 |
                 v
              FastAPI
                 |
          Session 应用服务
          /    |    |    \
     剧情   活动  存档  NPC Runtime
      |      |    |       |
    data/  data/ data/  characters/
                        scripted(默认) / hybrid / agent
```

## 8.2 所有权原则

1. **后端决定**：位置、时间、资源、关系、flag、剧情闸、奖励
2. **Vue/Phaser 负责**：输入、表现、预测，不自行提交永久事实
3. **普通内容优先数据化**：修改 JSON/schema 扩展，只有新交互形态才新增组件
4. **scripted 必须完整可玩**：模型能力只做可回退增强
5. **行动先完整校验再原子提交**：失败不留部分状态

## 8.3 0.6.0 数据扩展

| 新增 | 位置 | 说明 |
|---|---|---|
| 物品定义 | `data/world/items.json`（新增） | 物品 ID/名称/类型/效果/来源 |
| 采集点定义 | `data/world/gathering.json`（新增） | 采集点位置/产出/刷新规则 |
| 日常任务 | `data/world/daily_quests.json`（新增） | 任务定义/触发条件/奖励 |
| 熟练度规则 | `data/world/skills.json`（新增） | 熟练度阈值/解锁效果 |
| 烹饪配方 | `data/world/recipes.json`（新增 P1） | 配方/材料/产出/buff |
| WorldState 扩展 | `backend/app/models.py` | 增加 inventory/skills 字段 |

## 8.4 扩展规则

- 新普通活动：优先修改数据文件；只有新交互形态才增加前端面板
- 新 NPC：增加角色目录+元数据+模式，不在多处硬编码
- 新永久字段：更新 model+存档兼容测试+客户端契约
- 新模型能力：通过 runtime 接入，必须有白名单/超时/预算/审计/scripted 回退

# 第十二章：规则与约束

## 12.1 不可破坏的边界

- FastAPI 是位置、时间、资源、flag、关系、剧情闸和永久记忆的权威
- scripted NPC 是无模型 API 时的完整产品基线；hybrid/agent 必须可回退
- 被拒绝的行动不得部分写入状态
- 未审核素材不得进入 runtime
- `runs/`、`data/memory/`、`frontend/dist/`、密钥和本地环境不得提交
- 架构所有权变化先写 ADR；产品范围变化先修改本文件

## 12.2 文档纪律

- 不新增日期型 status、handoff、upgrade、phase 或版本副本
- 不创建新的 v003/v004 写作文档副本；所有内容变更直接修改本文件或 `GAMEPLAY_DESIGN.md`
- 玩家可见名称使用自然语言，不暴露内部 ID
- 旧事实使用 Git 历史追溯，不在仓库内继续复制归档文档

## 12.3 完成前必须运行

```bash
./scripts/quality.sh
./scripts/release.sh   # 仅在准备发布时运行
```

## 12.4 成功标准

### 原始标准
- 3/3 盲测玩家知道自己是桐人并理解当前目标
- 3/3 能在无口头指导下完成第一次有效互动
- 至少 2/3 能连续抵达 N10
- 至少 2/3 能说出一次自己的选择如何影响后续反馈
- 桌面和移动端无阻塞性 UI 重叠
- 离线 scripted 模式完整可玩

### 0.6.0 新增标准
- 3/3 玩家在通关后能说出至少 2 种自己做过的日常活动
- 至少 2/3 玩家注意到关系数值变化并理解其含义
- 至少 1/3 玩家主动尝试了主线之外的探索
- 至少 1/3 玩家表示"想再玩一次看看不同选择"
- 通关后记忆图鉴可正确展示所有选择路径

## 12.5 权利边界

当前原型包含《刀剑神域 Alicization》的既有角色、名称和设定。内部研发不等于拥有公开发行权。公开展示、分发或商业化前，必须完成授权评估；若无法获得适当权利，应将世界、角色、术语、剧情锚点和视觉识别整体原创化。

## 12.6 冻结项

以下不得作为当前阻塞项或另起规划：

- 旧见习记录员路线
- Day/月度内容继续扩写
- Cocos 迁移、全 3D、联网多人
- 全角色、全地图、全配音批量生产
- 无边界 Agent Loop
- 未经原型验收直接接入完整战斗
- 不在 0.6.0 阶段创建新的写作文档版本副本
