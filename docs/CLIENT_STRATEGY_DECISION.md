# 客户端路线决策记录

更新日期：2026-05-15

## 当前决策

当前主开发路径回到 `frontend/` 的 Vue + Phaser 客户端。  
`cocos-client/` 暂时冻结为未来备用正式客户端样板，不再作为近期 Demo 的阻塞项。

## 原因

- Cocos Creator 首次启动、登录、弹窗和编辑器预览流程会打断快速迭代。
- 当前 Vue + Phaser 客户端已经能在浏览器直接打开、自动化测试、截图和调试。
- 现阶段核心目标是把 20-30 分钟单人 Demo 打磨到可玩、可理解、流畅，而不是先迁移到更重的编辑器工作流。
- Cocos 已完成的 API 契约、DTO、地图渲染和场景样板仍有价值，适合以后需要正式客户端时再恢复。

## 执行原则

- 不删除 `cocos-client/`。
- 不继续把 Cocos Creator 登录、预览、按钮验收列为当前任务。
- 新功能默认先落在 Vue + Phaser 客户端。
- 后端 FastAPI 继续作为唯一权威世界状态。
- 共享契约、地图 visual 配置、tileset manifest 继续保留，避免未来迁移时重新设计。

## 下一步主线

1. 继续优化 Vue + Phaser 地图可读性和美术表现。
2. 把可走区域、道路、水岸、森林、障碍和 NPC 落点做得更自然。
3. 继续降低卡顿，保证点击移动、镜头、交互反馈流畅。
4. 推进正式 UI、日志、NPC Profile、Day 1/Day 2 内容体验。
5. 在需要更正式打包或美术管线时，再重新评估是否恢复 Cocos。
