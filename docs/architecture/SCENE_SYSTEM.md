# 场景与地图系统

## 当前实现

Vue 负责界面与面板，Phaser 负责地图、角色、移动、镜头、碰撞、POI 和空间互动。FastAPI 决定权威位置、可用行动和剧情结果。

## 数据流

```text
地图 JSON / 场景活动数据
→ Phaser 创建世界与交互对象
→ 玩家移动到人物或 POI
→ Vue 打开对应面板
→ 请求 FastAPI 提交行动
→ 返回权威状态与结果
→ Phaser/Vue 同步画面
```

## 地图职责

地图数据应包含：

- 稳定 map ID；
- 尺寸、tile size、spawn；
- walkable 与 collision；
- scene zones 与 POI；
- 视觉、镜头、移动和性能配置；
- 可选的 tileset/runtime 素材映射。

背景插图不能替代 walkable、collision、occlusion 和 interaction 数据。

## 交互职责

- Phaser 检测附近人物或地点。
- `activityRegistry` 选择已有面板与完成流程。
- Vue 只展示一个最强附近互动。
- 未知活动安全降级，不猜测 effects。
- 行动提交后以服务端返回状态校正角色位置和 UI。

## 当前地图目标

当前只需要把卢利特村序章做深：

1. 村庄主地图能够辨认教会书库、巨神树、三人住处、村广场和北门。
2. 尽头山脉可以先使用小型独立场景或受限事件场景。
3. 抓捕终点以村中事件场景表达，不要求立即制作第二张完整开放地图。

## 美术和性能

- 使用正交或轻俯视角，无可见网格。
- 角色比例、脚底锚点、遮挡层和碰撞盒一致。
- 静态层可烘焙，天气和水面按性能预算降低刷新频率。
- Phaser chunk 优化以实际首屏测量为依据，不为消除警告破坏结构。

## 扩展条件

只有当前村庄地图通过桌面、移动、碰撞、遮挡、地标和角色比例验收后，才新增完整地图。新场景必须复用客户端契约和后端权威状态，不建立独立规则系统。
