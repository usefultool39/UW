# MVP 范围：卢利特村三日纵切片

- **状态**：Current
- **目标版本**：0.x Preview

## MVP 要证明

1. 安静村庄日常可玩且易懂。
2. 资源判断和短玩法能支撑叙事。
3. NPC 记忆会产生可见关系后果。
4. 异常能从背景细节逐步升级为目标。
5. 无 API 时完整，接 API 时可增强。

## 必须包含

- 清晰开场、新手目标、地图操作和 Day 1–3 闭环。
- 阅读、训练、关系选择、北境巡查至少各一次。
- HP/MP/体力/时间/flag 权威结算。
- 爱丽丝、尤吉欧、赛鲁卡固定对话及后续回响。
- scripted/hybrid/agent 稳定接口和失败回退。
- 存档、内容校验、关键自动化测试、macOS 一键入口。

## 明确不包含

完整第一月最终打磨、多地图开放世界、联网/多人、依赖付费 API 的主线、大规模 Cocos 重写、无限 NPC 自由行动。

## 退出标准

- [ ] 3 名首次玩家中至少 2 名无需口头指导完成 Day 1。
- [ ] 玩家能说出主目标并理解至少一种资源代价。
- [ ] 三日流程无 P0/P1 阻塞缺陷。
- [ ] 至少两次早期选择有后续可见回响。
- [x] 后端测试、前端构建、关键 E2E 可自动执行。
- [x] 无 API 可完整游玩。
- [ ] 干净环境安装与旧存档兼容检查通过。

新想法若不直接改善“上手、可玩、关系后果、逐渐不安”，进入 Backlog，不挤占当前阶段。

## 日期推进与剧情闸（2026-08-05）

MVP 的日期推进不采用“玩家主动推荐下一天”的方式，而采用剧情事件驱动：玩家完成当日关键事件后，夜间结算或剧情转折自动开启下一天。

### 必须包含

- 每一天至少有一个 `required_story_event` 或明确的 `day_end_gate`。
- 未完成必需事件时，休息只能恢复资源或推进时间段，不能直接跨日。
- 关键事件完成后，后端自动生成日结算并进入下一天。
- 自动 NPC 日程和环境模拟继续运行，但不得绕过剧情闸。

### 不包含

- 随时可点击的“时间推进”“推荐日期”“跳过今天”按钮。
- 通过调试入口以外的客户端 `set_day` 或任意改日期操作。
