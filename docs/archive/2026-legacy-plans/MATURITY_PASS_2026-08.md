# UW 成熟化目标与执行方案

日期：2026-08-02

## 产品目标

把《边境回声》收束为一款发生在 Underworld 分支时间线中的单人叙事 RPG。玩家是卢利特村的见习记录员，通过日常、调查、训练与关系选择逐渐发现世界规则异常。

本阶段最高优先级：

1. 可玩性：每 3-5 分钟产生一次行动、收益或明确后果。
2. 吸引力：开场 60 秒建立 Underworld、角色关系和异常悬念。
3. 易上手：任何时刻只有一个主线目标；地点、成本和收益可预览。

## 参考作品的可执行提炼

- 《元气骑士》：输入后立即反馈、短循环、明确奖励，不照搬战斗内容。
- 《魔塔》：行动前可理解成本与收益，选择产生可预测的策略差异。
- 《邪恶冥刻》：逐步暴露规则背后的异常，让系统本身参与叙事悬念。
- 《夏日狂想曲》：以日程、地点与关系阶段组织长期内容。

## 核心循环

日常目标 → 地图行动 → 互动/小游戏 → 获得线索或关系变化 → NPC 记住选择 → 解锁新目标 → 日结算。

每个循环必须包含：一个明确目标、一个可操作行为、一个即时反馈、一个后续影响。

## NPC 双运行模式

所有模式共享世界状态、记忆、关系、故事导演和规则校验，仅替换 NPC 的意图选择与语言表达。

- `scripted`：默认，完全离线，规则与人工文本驱动。
- `hybrid`：关键剧情固定，普通表达和非关键意图可由模型生成。
- `agent`：模型可在允许目标中提出行动意图，后端仍负责合法性和结果。

环境变量：

```env
NPC_RUNTIME=scripted
NPC_RUNTIME_ALICE=agent
NPC_RUNTIME_EUGEO=hybrid
```

任何模型错误、超时或无 Key 状态必须回退到 scripted，且不能阻断主线。

## 第一版成熟 Demo 验收

- 30-45 分钟完成 Day 1-3 精简主线。
- 新玩家 10 秒内知道自己是谁、在哪里、下一步做什么。
- 主界面不同时显示互相冲突的主线目标。
- 玩家行动前能看见大致成本/收益。
- 至少三次主动选择，至少两名核心 NPC 在后续行动中体现记忆。
- 不配置模型 API 也能完成全流程。
- API 模式与固定模式共用存档和剧情事实。

## 近期顺序

1. 修复首屏目标冲突、开发文本暴露和信息过载。
2. 统一 Underworld 分支版公开术语，内部 id 保持兼容。
3. 打磨教会书库、巨神树伐木场、村庄广场、记录员小屋、北方村门。
4. 让读书、训练、日常选择形成明确收益和连续奖励。
5. 让爱丽丝、尤吉欧先在 scripted 模式拥有目标、承诺、记忆与主动行为。
6. 冻结 Day 46 以后扩写，优先完成可公开试玩的前 30-45 分钟。
