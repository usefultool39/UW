# UW 成熟化第二轮：探索、风险与奖励

日期：2026-08-03

## 本轮目标

第一轮解决“玩家不知道做什么”，第二轮解决“玩家知道做什么，但缺少真正需要判断和承担风险的玩法”。

优先级仍然是：

1. 可玩性：增加 2-4 分钟可重复的危险探索短循环。
2. 吸引力：让北境异常不只存在于文字，而是能伤害玩家、消耗资源并留下战术记录。
3. 易上手：敌方意图公开，克制规则固定，行动成本和结算结果全部可见。

## 新玩法：北境短程巡查

解锁条件：完成 Day 2 森林异常调查（`forest_anomaly_seen`）。

地点：北境边门。

流程：

```text
查看敌方意图
→ 在格挡 / 神圣术 / 侧步中选择
→ 即时扣除临时资源并显示反馈
→ 连续处理三次威胁
→ 按表现获得 S / B / R 评价
→ 后端结算生命、神圣力、体力、关系、记忆和边境标记
```

克制规则：

- 正面冲撞 → 架势格挡
- 聚能咏唱 → 神圣术·束光
- 范围横扫 → 侧步突进

这套规则借鉴动作游戏的即时反馈，但保留《魔塔》式的行动前成本可读性。敌方不靠随机隐藏信息制造挫败；玩家失误后仍能保住部分记录并撤退。

## 权威结算

前端负责战术交互和表现反馈；最终资源、关系、记忆与累计标记由后端活动规则结算。

新增活动结果：

- `hp_cost`
- `mp_cost`
- `stamina_cost`
- `resource_changes`
- `flag_deltas`

危险活动会先检查所有资源，再写入 flags、关系和记忆，避免失败请求造成半结算状态。

## 恢复循环

休息和睡眠现在恢复：

- 生命 HP
- 神圣力 MP
- 体力 Stamina

由此形成：

```text
巡查消耗 → 获得标记 → 关系/记忆变化 → 回家休息 → 次日再次行动
```
