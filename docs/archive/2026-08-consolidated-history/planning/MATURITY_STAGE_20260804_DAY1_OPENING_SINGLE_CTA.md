# WP-1E 冻结方案：Day 1 开场单一 CTA

- 日期：2026-08-04
- 状态：Frozen / implementation slice
- 对应阶段：`NEXT_PHASE.md` 的 WP-1「首次玩家路径」
- 优先级：P0（首次玩家可理解性）

## 体验审计

桌面与移动截图显示开场同时提供“开始记录”和“开始行动”两个近义按钮。两者都会关闭开场，但一个尝试定位第一条事件，另一个只提示玩家跟随指引；玩家无法在按钮文字上判断差异。实际代码还保留了一个由两者共同跳过的 brief 状态，导致开场路径存在重复/不可达的心智模型。

## 冻结改造

- 开场只保留一个主 CTA：`定位第一条线索`。
- CTA 继续使用既有 `focus-first-event` 行为：关闭开场、把镜头带到第一条线索、提示玩家跟随金色指引；不直接结算事件、不绕过地图移动。
- 在按钮旁用一句短文案解释点击后的动作，避免把“定位”误解为“立即完成”。
- 不增加新系统、不改变后端状态、剧情、资源或 NPC runtime；保留 skip emit 兼容接口，未来 scripted / hybrid / agent 仍共享同一开场状态边界。

## 验收

1. Day 1 初次开场只存在一个可见主 CTA，旧“开始行动”入口不存在。
2. 点击后能看到三步行动提示和“线索 → 选择 → 关系回响”短循环 HUD。
3. 关键 Day 1–3、长线 smoke、后端测试、前端单测、build 全部不回归。
4. 真实首次玩家盲测仍是后续证据，不以自动化测试替代。
