# WP-1F 冻结方案：Day 1 引导层级去重

- 日期：2026-08-04
- 状态：Frozen / implementation slice
- 对应阶段：`NEXT_PHASE.md` 的 WP-1「首次玩家路径」
- 优先级：P0（UI 层级与上手速度）

## 体验审计

点击开场 CTA 后的桌面截图同时出现三层同义引导：左上大型“路线追踪”卡、左侧短循环卡、右侧主线目标卡。大型路线卡和右侧主线按钮都会引导同一条事件，既重复操作入口，也遮挡地图；代码注释声称只保留开场与右侧主线卡，但实际模板仍渲染该卡。

## 冻结改造

- 移除独立 `newcomer-guide` 大卡及其专用计算、点击函数和 CSS。
- 保留右侧 `QuestTracker` 作为唯一可点击主目标入口：目标、地点、收益、今日节奏和三步提示仍在同一层。
- 保留左侧 `LoopRibbon` 作为不可点击的短循环/关系回响解释，不与主目标争夺操作焦点。
- `newcomerGuideVisible` 继续只用于高亮主线卡和显示桌面三步提示；移动端继续使用已有主线卡按钮。
- 不改地图、后端状态、事件可达性、剧情或 NPC runtime。

## 验收

1. 开场关闭后不存在 `.newcomer-guide`，但右侧主线按钮仍恰好一个。
2. 三步提示和短循环 HUD 继续可见，地图左上遮挡面积减少。
3. 桌面/移动截图、前端 build、后端测试与完整 E2E 全绿。
