## 3. 逐组详细审查

### 3.1 `REF-STYLE-001`：三套方向板 —— 通过，但必须当成“方向合同”

三张方向板本身是程序化绘制的视觉规范，不是最终素材。它们的价值在于已经形成了可执行的颜色、材质、光线和字体语义：

- **方向 A：雨后初晴的北境秩序**
  - 适合开场、村庄、第一次移动。
  - 给玩家安全、清晰、可居住的第一印象。
  - 推荐承担“容易上手”的视觉入口。
- **方向 B：旧书库与烛光律法**
  - 适合书库、记录、档案、阅读选择。
  - 能支撑“读记录不是纯文本，而是在权威中寻找漏洞”的玩法语气。
- **方向 C：静默线边界**
  - 适合异常、边界、声音消失、悬念升级。
  - 不适合作为首屏主色，否则会让新玩家误判为暗黑战斗游戏。

**冻结意见**：保留 A/B/C 三套，但不是三套并列主题。必须执行 `A → B → C` 的叙事层级：先让玩家放心，再让玩家查证，最后让玩家感到规则出现裂缝。

**问题**：三套方向板有明确 token，但仍是色板/缩略示意，缺少统一的最终材质、角色、地图、字体在真实 UI 中的组合验证。因此批准“方向”，不批准“最终美术标准已完成”。

**重做要求**：保留当前构图和版本意图，重新导出：

- 桌面：真实 PNG，`2560×1440`；
- 移动：真实 PNG，`1440×1920`；
- 无水印、无签名、无 UI、无 Exif 依赖；
- 交付后更新 sidecar 的实际尺寸、sha256 和 `MANIFEST.csv` 状态。

v001 版本（`direction_a/b/c`）保留为变更请求证据即可，不再派生。

**复核更正（2026-08-05 二次）**：上述问题已在返工中解决。当前 6 张 v002 均为真实 PNG，桌面 `2560×1440`、移动 `1440×1920`，无水印；sha256 与 `MANIFEST.csv` 一致。下一步是接入开场/书库/边界状态并做真实 UI 截图，不再需要重导。

### 3.3 `VIS-POR-001`：肖像 —— v002 的角色方向可保留，master 透明度返工后已达标

#### v001：明确退回

v001 使用了 `kirito` 命名或明显靠近《刀剑神域》角色的外观，并且部分带右下角生成水印。即使当前项目 README 将项目定义为非商业二次创作，也不应把这组资源当作新的正式生产资产。它们只能留在审查历史里。

#### v002：视觉候选成立，文件实物不成立

v002 已经把玩家改成原创“Record Keeper/见习记录员”，并让 Alice/Eugeo 的服装功能更靠近本项目的劳动、记录、书库语境；这是正确的去水印/去复刻方向。

但实物检查发现：

- 六张 v002 master 文件名是 `.png`，实际格式为 JPEG；
- 实物为 3 通道，不含 alpha；
- 联系图中可见棋盘格背景已被烘进图像；
- sidecar 写的是 `1024×1024 RGBA 透明背景`，与实物不一致。

**结论**：这不是“抠图小瑕疵”，而是不能直接进入 UI 的技术退回。需要从当前 v002 源图重新导出真正的 RGBA PNG；修复后再派生 256 缩略图。

当前 v002 256 图虽有 alpha，可作为审查或临时预览，但不能因为 256 图透明就把 master 判为合格。接入前还要检查：

- 发丝、武器/工具、书本边缘是否有棋盘格残留；
- neutral/concerned 是否保持角色服装与轮廓一致；
- 24–48px UI 中是否仍能看出人物状态；
- 与地图 token、对话框头像的画风和比例是否一致。

**复核更正（2026-08-05 二次）**：上述“实物不含 alpha”的问题已在返工中解决。当前 6 张 v002 master 均为真实 RGBA PNG `1024×1024`，四角 alpha=0，无棋盘格残留；角色区约 23–43% 不透明，边缘约 1.5–2.8% 半透明渐变；256 派生图存在且 hash 一致。接入前仍需做边缘、缩放与角色一致性 QA。

### 5.2 最应该保持的部分

1. **短循环不要再加新系统**：玩家每次行动都应看得懂代价、收益和回响。
2. **首屏不要直接上边界紫雾**：先用 A 的村庄安全感，再让 B 的记录权威建立规则，C 只在异常升高时出现。
3. **后端仍然做最终裁决**：未来 AI 只能负责表达和意图建议，不能直接改关系、奖励、flag 或记忆。
4. **关系回响要比“奖励数字”更具体**：结果面板应该让玩家看到“谁记住了什么、明天因此多了什么选择”。
5. **不把地图扩大当作内容进度**：当前 Day 1–3 的小区域如果能形成可重复短循环，比一次性增加新区域更有价值。

## 7. 交付前必须满足的“素材通过”定义

一组素材只有同时满足以下条件，才能从 `inbox` 进入 `approved` 或 runtime：

- sidecar、manifest、实际文件格式和尺寸一致；
- 文件名扩展名与真实 MIME 一致；
- alpha/透明背景类资源经实际像素检查；
- 视觉角色和状态在 24–256px 的目标尺寸下可辨；
- 音频响度、采样率、声道、时长和循环点有证据；
- 许可证、来源、工具/模型、生成日期和 hash 可追溯；
- 在真实游戏里至少完成一次接入截图或试玩验证；
- 影响 Day 1–3 的新增资源通过三人盲测后，才可称为“改善易上手”。
