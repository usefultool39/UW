# 产品需求

- **状态**：Current
- **范围**：`0.5.0-pre-capture` 与可扩展 RPG 基础
- **最后更新**：2026-08-07

状态：`Done` 已实现并验证；`Partial` 已有可复用能力但尚未达到本阶段验收；`Planned` 尚未完成。

## 功能需求

| ID | 需求 | 优先级 | 状态 |
|---|---|---:|---|
| FR-001 | Windows/macOS/手动方式可启动，脚本模式不依赖外部 API | P0 | Done |
| FR-002 | 地图移动、地点/POI 调查、对话和活动入口可用 | P0 | Done |
| FR-003 | 行动前展示主要代价、收益和锁定原因，失败不部分写入 | P0 | Done |
| FR-004 | 关系、记忆、承诺、紧张和线索跨事件保留并按 run 隔离 | P0 | Done |
| FR-005 | 四幕、8–12 个关键节点忠实覆盖日常到爱丽丝被带走 | P0 | Done |
| FR-006 | 抓捕是唯一正式终点，写入匹配 ending，终点后本章不可继续推进 | P0 | Done |
| FR-007 | 日期只由剧情闸/日结算推进，普通活动不能绕过必需事件 | P0 | Done |
| FR-008 | 至少 6 类生活/探索活动与主线、关系或世界规则相关 | P0 | Partial |
| FR-009 | 至少 3 次选择产生跨节点可见回响，但不改变正典终点 | P0 | Done |
| FR-010 | 存档可导入导出，新增字段有默认值和兼容测试 | P0 | Done |
| FR-011 | 主线地图、角色 Sprite、互动动作、场景层、UI/VFX 和基础音频完成运行时接入 | P0 | Planned |
| FR-012 | 素材必须有 request、sidecar、来源/权利、manifest、验收与回滚记录 | P0 | Partial |
| FR-013 | 单个 NPC 可切换 scripted/hybrid/agent，模型不能提交权威效果 | P1 | Partial |
| FR-014 | 独立战斗原型比较候选制式，通过评审后才接入正式主线 | P2 | Planned |
| FR-015 | 3 名陌生玩家完成全程盲测并记录卡点、时长、理解度和继续意愿 | P0 | Planned |

## 正典与内容要求

| ID | 目标 |
|---|---|
| CAN-001 | A/B 类正典事实必须来自登记来源；C 类原创补充不得替代关键事实 |
| CAN-002 | 桐人、尤吉欧、爱丽丝的称谓、动机、关系与时间线在玩家可见内容中一致 |
| CAN-003 | 禁止提前出现抓捕后身份、中央大教堂后期状态或 War of Underworld 剧透 |
| CAN-004 | 每个关键节点必须标注幕、顺序、进入条件、效果、回响和正典依据 |
| CAN-005 | 候选写作素材经人工合并和连续性检查后才能进入 `data/story` |

## 表现与可访问性要求

| ID | 目标 |
|---|---|
| UX-001 | 新玩家 60 秒内完成第一次有效互动；同屏只保留一个最强主行动 |
| UX-002 | 关键文本不只依赖颜色；字号、对比度、焦点态和触控目标可读可操作 |
| UX-003 | 动画、闪烁、镜头震动和音量提供降低或关闭选项，剧情信息有非音频表达 |
| UX-004 | 桌面与移动视口无关键 UI 重叠，键鼠和触控均可通关 |
| ART-001 | 角色缩小后仍可识别，比例、脚底锚点、方向、光照、轮廓和调色统一 |
| ART-002 | 核心角色至少具备 idle、四向 walk、interact；战斗角色另按原型动作集验收 |

## 工程与生产要求

| ID | 目标 |
|---|---|
| NFR-001 可维护 | 新内容通过稳定 ID、schema 和数据文件扩展，不持续扩大巨型分支 |
| NFR-002 可测试 | pytest、前端单测、build、E2E、材料与正典检查作为质量门 |
| NFR-003 可靠 | 后端权威决定位置、时间、资源、剧情闸、关系和永久记忆 |
| NFR-004 性能 | 首屏、图集、音频和 Phaser chunk 有预算；弱设备按测量结果降级 |
| NFR-005 可观察 | 健康检查、按 run 日志、剧情回放和素材 hash 可追踪 |
| NFR-006 安全 | 密钥仅存环境变量；模型输出经过白名单、预算、超时和审计 |
| NFR-007 文档一致 | 产品方向、当前状态、下一阶段和素材台账各有唯一权威入口 |
| NFR-008 权利 | 生成/外部素材记录来源、许可和用途；公开发布前完成 IP 评估 |

## 变更规则

产品边界变化先更新本文件与 MVP；状态所有权、API、存档或 NPC 权限变化必须有 ADR 和回归测试。任何“完成”都必须对应可检查证据，不能用候选素材或自动测试替代真人验收。
