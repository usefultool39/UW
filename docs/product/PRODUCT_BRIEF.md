# 产品简述：边境回声 · Pre-Capture 篇

- **状态**：Current
- **目标版本**：`0.5.0-pre-capture`
- **最后更新**：2026-08-07
- **权威基线**：[PRODUCT_DIRECTION.md](PRODUCT_DIRECTION.md)

## 一句话愿景

一款面向大众、容易上手但有持续深度的 2D 单人叙事 RPG：玩家在卢利特村的生活、劳动、探索与关系选择中建立对三人日常的依恋，再亲历越界事件以及爱丽丝被带走的固定结局。

## 当前定位

- 主线忠实还原《刀剑神域 Alicization》前期从卢利特村日常到爱丽丝被带走的事件顺序；不再采用“原创见习记录员分支线”作为当前产品定位。
- 可玩内容允许补充日常活动、村民互动、调查细节和选择回响，但不能替换、颠倒或取消正典关键事实。
- 交互借鉴日程型生活叙事的“时间段 + 地点 + 关系 + 活动”组织方式；美术采用原创、清晰、明快、易识别的 2D 卡通表现。
- 当前客户端保留 Vue 3 + Phaser 3，后端保留 FastAPI；不为框架观感迁移到 Cocos 或 3D。
- 大模型只增强候选表达，`scripted` 模式必须独立完成全部主线。

## 玩家体验

```text
查看目标 -> 选择地点与活动 -> 操作或判断 -> 获得即时反馈
-> 写入关系/记忆/承诺/线索 -> 日结算 -> 解锁下一节拍
-> 日常逐步失衡 -> 越界 -> 告别 -> 爱丽丝被带走
```

玩家应在 60 秒内完成第一次有效互动，并始终知道当前目标、行动代价和结果。活动不是无关填充：砍伐、取水、读书、送物、练习、观察、用餐和探索都必须服务于人物关系、世界规则或后续事件。

## 内容承诺

- 四幕、8–12 个关键节点，唯一正式终点为爱丽丝被整合骑士带走。
- 桐人、尤吉欧、爱丽丝的动机、关系和行为符合当前正典事实表。
- 至少三次选择在后续节点产生可见回响，但不改变抓捕事实。
- 地图、角色 Sprite、动作、UI、VFX、音频和数据 sidecar 按完整制作管线管理，不以单张静态图冒充完整游戏美术。
- 战斗在后续独立原型中验证；当前阶段只保留可扩展接口和动作规格，不让半成品战斗阻塞主线。

## 非目标

- 当前不制作爱丽丝被带走之后的剧情。
- 不做 MMO、联网多人、开放世界、无限生成剧情或全 3D。
- 不直接复制参考作品的台词、画面、UI、音乐、数值或关卡。
- 不继续扩写 Day 118+，不把旧月度循环当作当前正典完成度。

## 成功信号

- 新玩家无需口头说明即可完成主线，并理解爱丽丝被带走的原因和三人关系变化。
- 生活活动有选择、有反馈、有回响，玩家愿意在终点前继续探索可选内容。
- 桌面与移动端信息清晰，键鼠和触控均可完成关键流程。
- 自动化、材料审计和真人盲测都有证据；候选素材不会被误报为正式完成。
