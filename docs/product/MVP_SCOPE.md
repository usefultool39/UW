# MVP 范围：0.5.0 Pre-Capture 正典纵切片

- **状态**：Current
- **最后更新**：2026-08-07
- **叙事边界**：卢利特村日常开始，爱丽丝被整合骑士带走结束

## MVP 要证明

1. 卢利特村日常本身有可玩性，且能建立玩家对三人关系的投入。
2. 生活活动、资源判断和选择回响能自然推动正典事件，而不是把剧情做成文字播放器。
3. 原创补充内容可以丰富体验，同时不改写 Alicization 的关键事实和人物动机。
4. 当前技术栈能承载完整的地图、动作、特效、音频、存档和内容生产流程。

## 必须包含

- 四幕、8–12 个有稳定 ID 的关键节点，顺序覆盖日常、尽头山脉、越界、返村/告别与抓捕。
- 唯一正式终点 `alice_captured` 或 `precapture_alice_captured`，终点后禁止继续推进本章剧情。
- 至少 6 类短活动，至少 3 次跨节点关系/记忆回响，并提供失败或低资源恢复路径。
- 可走地图、关键角色四向移动、核心互动动作、主要场景层、必要 UI/VFX、BGM/环境声/SFX。
- 行动前可理解代价与收益；结果、目标、锁定原因和下一步清晰可见。
- `scripted` 模式完整可通关；存档导入导出、旧存档兼容和内容校验可用。
- 桌面和移动视口不遮挡；键鼠和触控均可完成关键流程。
- 后端、前端、构建、E2E、材料审计、正典连续性检查和真人盲测均有记录。

## 明确不包含

- 爱丽丝被带走之后的剧情。
- 完整正式战斗、开放世界、联网多人、全 3D、Cocos 迁移。
- 大规模配音、全角色全服装动作包或无限生成 NPC 行为。
- 将候选生成图、概念图或临时占位图标记为正式完成。

## 退出标准

- [x] 四幕主线和唯一抓捕终点通过 Pre-Capture story readiness 检查。
- [ ] 新玩家 60 秒内完成第一次有效互动，能复述当前目标和一次行动代价/收益。
- [ ] 3 名陌生玩家均完成主线；至少 2 名无需口头引导。
- [x] 至少三次早期选择在后续节点产生可见回响。
- [ ] 正典、地图、动作、UI、音频和素材来源无 P0 缺口。
- [ ] 桌面与移动端关键流程无重叠、断路或不可读文本。
- [ ] 全部自动质量门通过，且没有把“自动化通过”误写成“真人盲测完成”。
