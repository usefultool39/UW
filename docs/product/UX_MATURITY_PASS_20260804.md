# 第一轮成熟化改造冻结方案（2026-08-04）

## 审计结论

首屏已有强叙事画面、主线目标和 Phaser 地图，但玩家在关闭开场后仍要自行拼出“我现在做什么、做完得到什么、下一步为什么值得做”。右侧任务卡同时承载主线、附近互动、同伴事件和未来线索，信息是全的，优先级却不够强。行动结果已有弹窗和 Toast，但“短循环”和“关系回响”没有在行动前被稳定预告。

## 本轮冻结范围

1. **开场三步**：保留叙事开场 → 明确今日目标 → 关闭开场后继续显示一次“看金色指引 / 走近目标 / 做出选择”的短引导；不新增大系统。
2. **短循环提示**：在场景 HUD 增加固定的“线索 → 选择 → 回响”三段式提示；没有剧情线索时切换为“地点行动 → 管理资源 → 日程结算”。
3. **奖励反馈**：保留服务端最终裁决，在任务卡展示完成收益预览，在结果面板继续展示关系变化、记忆、承诺/紧张与下一条线索。
4. **日程/关系推进**：短循环卡显示当前主动邀约 NPC 和“会记住你的选择”提示；日志继续承载完整日程、关系和记忆。
5. **固定 NPC / 未来 AI**：前端明确显示 scripted / hybrid / agent 运行态；三种模式共享同一世界状态和结果面板，智能体只作为意图/表达来源，不绕过后端规则。
6. **兼容性**：不重写 `FieldSlice.vue`、Phaser scene、`npc_intents.py`；新增纯展示组件，所有字段缺失时使用离线安全文案。

## 验收标准

- 新玩家首次关闭开场后，3 秒内能看到唯一下一步和三步操作提示。
- 主线任务卡同时给出：目标地点、完成收益、今日节奏。
- 完成一次行动后，玩家能在结果面板看到至少一项数值/关系/记忆反馈，并能看到下一条线索或“继续行动”。
- scripted 模式离线可玩；切换 hybrid/agent 不改变后端世界事实与奖励裁决边界。
- 后端测试、前端单测、前端构建和关键 Day 1 / Day 2 试玩流程通过。
