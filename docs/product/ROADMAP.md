# 产品路线图

- **状态**：Current
- **最后更新**：2026-08-07

路线图只描述阶段结果；当前开工顺序以 [NEXT_PHASE.md](../planning/NEXT_PHASE.md) 为准。

## Now：0.5.0 Pre-Capture 正典纵切片

- 审核并合并候选世界观、人物和正典资料。
- 写入四幕、8–12 个关键节点以及唯一抓捕终点。
- 将现有生活活动、关系、记忆、日结算和日期闸接入正式主线。
- 补齐主线阻塞素材：可走地图、角色 Sprite、核心互动动作、场景层、UI/VFX 和基础音频。
- 完成连续性校验、自动回归和 3 名陌生玩家盲测。

## Next：0.6.x 生活与表现成熟化

- 扩展可重复活动、日程、天气和关系回访，提升重玩差异。
- 统一地图贴图、角色比例、动作帧、光照、特效与音频层级。
- 完成键鼠/触控可用性、文字可读性、难度辅助和弱设备预算。
- 建立批量导入、图集打包、碰撞/锚点校验和素材回滚工具。

## Later：0.7.x 独立战斗原型

- 在独立场景验证实时、半实时或指令制方案，不直接污染正式主线。
- 为桐人、尤吉欧、爱丽丝和一个敌人制作完整最小动作集。
- 比较可读性、操作负担、移动端适配、内容成本和与关系系统的联动。
- 只有通过原型验收后才确定正式战斗制式和接入计划。

## Future：0.8.x 章节扩展

- 在 Pre-Capture 完成并稳定后，再规划爱丽丝被带走之后的章节。
- 新地图、成长、装备、敌人和剧情按章节独立交付、存档兼容和自动回归。
- 正式公开或商业化前完成整体原创化与 IP/素材权利评估。

## 冻结项

Cocos 迁移、全 3D、联网多人、无边界 Agent Loop、Day 118+ 扩写和完整战斗均不是当前阻塞项。
