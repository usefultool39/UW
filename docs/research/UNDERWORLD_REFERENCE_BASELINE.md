# Underworld 参考基线与游戏化转译

- **状态**：Current / 产品参考基线
- **日期**：2026-08-05
- **用途**：为《边境回声》第一章提供《刀剑神域 Alicization / Underworld》的设定参考边界，不是原作剧情复述，也不是台词素材库。

## 1. 资料范围

本基线优先参考官方动画剧情页面、官方角色/作品介绍和原作书目简介。重点不是逐集复述，而是提取可以转化为游戏结构的世界关系：露茵村日常、天职、禁忌规则、爱丽丝与尤吉欧的关系、越界事件和从村庄走向更大世界的转折。

## 2. 对本项目最有价值的设定

### 2.1 露茵村不是背景图，而是第一座“生活副本”

露茵村的价值在于：玩家可以理解这里的劳作、家庭、规则、人际关系和地理边界。第一章不应急于把玩家送出村庄，而应先让玩家熟悉“每天为什么做这些事”，然后用一个越界事件打破稳定。

游戏化：

- 书库：记录、知识、禁忌规则和线索整理。
- 古誓树/巨树：天职、训练、体力管理和尤吉欧关系。
- 家中炉火：吃饭、关系复盘、承诺和日结算。
- 广场：传闻、村务和社会压力。
- 北境边门：观察、巡查和进入冒险的出口。

### 2.2 天职适合成为日程系统

尤吉欧和伙伴承担固定劳动，这种“今天必须做什么”的结构天然适合生活 RPG。它不应被实现为无限重复的点击，而应每次提供轻微变化：天气、工具状态、NPC 情绪、玩家选择和异常线索改变今天的劳动结果。

### 2.3 禁忌规则适合成为选择压力

禁忌目録/教会规则的功能不是单纯的“不可做清单”，而是让玩家在好奇心、责任、同伴安全和记录真实之间做选择。游戏中的每次越界应有可理解的代价，不应让玩家因为没有读攻略而被突然惩罚。

### 2.4 爱丽丝与尤吉欧不能只做两条好感度

建议给两人不同的行动价值：

- 爱丽丝：更愿意探索和提出问题，重视记录完整、主动判断和保护重要的人。
- 尤吉欧：更重视天职、村庄责任、撤退和承诺，面对未知时更谨慎但不是被动。
- 玩家：不是在两条恋爱数值之间选高低，而是在两种世界判断之间形成自己的路线。

### 2.5 从日常到冒险必须由事件推动

原作的吸引力来自“熟悉的村庄生活”与“无法忽略的异常/越界”之间的反差。因此日期推进不应是无意义的日历计数，而应由关键事件推动：完成一次调查、触发一次关系承诺、发现一次规则矛盾、做出一次越界选择。

## 3. 时间线选择

### 第一章默认锚点：露茵村早期分支

本项目第一章建议停留在露茵村及其周边，使用“早期生活 + 原创玩家介入”的分支时间线。这样可以同时保留生活模拟的日程感和 Underworld 的规则悬念。

### 不要混入的内容

- 不要在 Day 1–3 同时使用童年露茵村、中央大教堂囚禁、整合骑士时期和 War of Underworld 战后状态。
- War of Underworld 的战后露茵村可以作为后续独立章节参考，但不应与第一章的天职劳动日程混为同一时期。
- 如果玩家角色继续使用“见习记录员”设定，Kirito 应作为世界背景/分支变量，而不是无理由替代玩家成为主角。

## 4. 第一章的剧情节奏建议

```text
日常可信
→ 记录出现矛盾
→ 训练/巡查中确认异常
→ 玩家在爱丽丝与尤吉欧的判断之间选择
→ 炉火日结算
→ 下一日目标自动开启
→ 第三天做第一次越界/守规选择
```

每一天都应该回答：

- 今天的生活任务是什么？
- 哪个角色会受到影响？
- 哪一条规则变得不再可靠？
- 完成今天后，明天新增了什么选择？

## 5. 与当前项目的对应修改

| 当前项目部分 | 需要调整 |
|---|---|
| `gigas_clearing` | 从普通砍树活动升级为“天职 + 训练 + 异常观察”场景 |
| `church_library` | 从阅读面板升级为“记录比对 + 规则判断”玩法 |
| `home_hearth` | 作为关系选择、承诺和日结算的正式剧情闸 |
| `north_gate` | 从远景预览升级为后续冒险的风险/撤退入口 |
| `day` | 从时间计数改为剧情节拍，由事件和日结算推进 |
| NPC memory | 从结果摘要升级为角色对玩家判断的长期依据 |
| Agent runtime | 先增强角色表达和主动意图，再允许低风险社会活动自主运行 |

## 6. IP 与素材边界

本文件只记录参考设定和设计转译，不复制原作文本、动画截图、官方 UI、音乐、角色定妆或特效。素材生成应继续使用可观察属性描述，例如“湿润高机位村庄、记录员工具 UI、克制的几何发光术式”，而不是要求模型直接模仿某部作品或某位作者的画风。
