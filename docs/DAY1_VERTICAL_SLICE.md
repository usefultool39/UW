# Day 1 完整体验脚本

更新时间：2026-05-12

目标：新玩家不看开发文档，也能自然完成第一天，并理解艾琳和尤里的不同态度。

## 关键节点

1. 清晨开场：玩家在露茵村醒来，右侧目标提示“去书库或古誓树清场”。
2. 玩家移动到书库阅览台，附近行动出现“拼接刻印术和旧记录线索”。
3. 读书玩法：玩家从旧记录里选择 3 个关键词。
4. 读书结果写入 flags、艾琳关系和记忆；日志可见“阅读线索”。
5. 书库章节事件出现：玩家决定把边界记录告诉艾琳，或先记在心里。
6. 艾琳反应：她会担心北边过分安静，或记住玩家暂时隐瞒。
7. 可选午餐篮：玩家偏向艾琳、偏向尤里，或沉默观察。
8. 午餐选择写入 flags、关系变化、NPC 记忆。
9. 玩家沿路前往古誓树清场。
10. 巨树训练入口出现：先进入节奏小游戏。
11. 训练小游戏：玩家点击或按空格完成 3 次节奏判定。
12. 训练剧情选择：按尤里节奏完成，或训练时追问边界。
13. 尤里反应：他把训练视为日常规则，也会对边界问题变得认真。
14. 可选“听北边的风”：玩家确认静默线伏笔。
15. 傍晚或夜晚回到炉火边。
16. 晚餐玩法：玩家偏向艾琳、偏向尤里，或把话题拉回日常。
17. 晚餐结果写入承诺或紧张点，并在 Profile / 日志中可见。
18. 玩家休息，触发 Day 1 日结算。
19. 日结算展示：关系变化、NPC 记住的事、下一天线索卡。
20. 镜头可聚焦 Day 2 目标，玩家知道明天要去确认静默线。

## 主动选择

- 读书关键词：异常线索完整 / 边界规则偏重 / 保留疑问。
- 艾琳反应：告诉她 / 暂时隐瞒。
- 午餐或晚餐：偏向艾琳 / 偏向尤里 / 保持沉默观察。
- 训练：稳定完成 / 追问边界。

## 验收

- Day 1 不依赖调试按钮。
- 除训练外，至少有 1 个轻量玩法互动；当前为读书关键词和餐桌关系选择。
- 玩家能在日志或 NPC Profile 中看到选择造成的关系/记忆变化。
- Day 1 结束后，日结算能预告 Day 2。
