# 第一章三日 Demo 试玩

面向：开发者、试玩者、接手项目的智能体。

## 启动

1. 后端健康检查：http://127.0.0.1:8765/api/health 返回 `ok`。
2. 前端打开：http://127.0.0.1:3000。
3. 页面默认进入地图主界面。

旧开发调试台仍保留，但试玩第一章时不需要进入调试台。

## 试玩流程

### Day 1：日常与线索

1. 阅读右侧“当前目标”。
2. 在地图上寻找金色 `!` 章节事件。
3. 触发以下事件：
   - `书库里的边界记录`
   - `巨树旁的训练`
4. 做任意选择。
5. 观察选择结果面板：应展示结果文本、关系变化、NPC 记忆。

### Day 2：异常出现

1. 点击地图顶部或快捷栏的休息/时间推进，进入第二天。
2. 触发 `森林忽然安静`。
3. 继续推进到傍晚或夜晚。
4. 触发 `晚餐桌边的分歧`。
5. 查看 Alice / Eugeo 对异常的不同态度。

### Day 3：规则冲突

1. 休息到第三天。
2. 触发 `第三天：边界线前`。
3. 选择一个结局：
   - 遵守规则，回村报告。
   - 越过边界，确认异常源头。
   - 隐瞒异常，暂时保护同伴。
4. 结局应写入 `chapter_ending_id`，并进入 NPC 重要记忆。

## 验收点

功能验收：

- 地图默认可见，Phaser canvas 正常加载。
- 玩家可以点击地图移动。
- NPC 在地图上可见并可点击。
- NPC 对话可用；无 LLM key 时 fallback 可用。
- 章节事件会按 day、time_band、flags、relationship 自然出现。
- 事件选择后显示结果面板。
- 关系变化和重要记忆可以在 NPC 档案中看到。
- Day 3 至少能进入一个结局。
- 导出存档、重置、导入存档后，世界状态和 NPC 记忆可以恢复。

体验验收：

- 玩家不用读开发文档，也能知道下一步大概做什么。
- 玩家能说出至少一个 NPC 为什么让他在意。
- 第一章不依赖调试台按钮才能跑通。

## 常见问题

### 地图没有事件

检查当前天数、时间段和 flags。事件触发规则在：

`data/story/events_chapter_01.json`

### 对话失败

无 key 或模型失败时应该自动 fallback。检查：

- `backend/app/dialogue_agent.py`
- `backend/.env`
- `/api/config`

### 存档没有恢复记忆

导出的 JSON 应包含：

- `state`
- `events`
- `memory_summaries`

后端导入入口在：

`POST /api/save/import`

### Windows 测试临时目录报权限错误

测试已覆盖项目内 `tmp_path` fixture，正常情况下应通过。如果还有权限问题，优先清理或避开这些历史目录：

- `.pytest-tmp/`
- `pytest_tmp/`
- `backend/.pytest_tmp/`
- `backend/.codex_pytest_base/`
- `backend/.codex_pytest_tmp/`

不要把这些目录当作项目状态源。
