## 更新规则

- 产品原则只在 `PROJECT.md` 与 `product/PRODUCT_DIRECTION.md` 维护。
- 完成度只在 `planning/CURRENT_STATUS.md` 维护。
- 下一步只在 `planning/NEXT_PHASE.md` 维护。
- 素材结论只在 `art/ASSET_REVIEW.md` 与 `materials` 台账维护。
- 不再新建“最终版、最新交接、升级版、第二版”文档；Git 历史承担版本追溯。
